# MiniMax H3 CUDA runtime — direct dependency pins for ~/.portos/minimax-h3-cuda/.venv.
#
# NOT a fully-resolved lock, unlike its MLX sibling
# (requirements-minimax-h3-mlx.lock.txt). `torch` is installed separately and
# from a different index depending on the host — PyTorch's own CUDA wheel index
# on Windows, plain PyPI elsewhere (where the default wheel already bundles
# CUDA) — so one resolved transitive lock cannot describe every install. Pinning
# the direct dependencies exactly is the strongest guarantee that holds for all
# of them.
#
# `torch` is deliberately absent for that reason — setup-image-video.sh installs
# it first, from the host's correct index (see WIN_TORCH_CUDA_INDEX in
# server/lib/pythonSetup.js, and PORTOS_TORCH_CUDA_INDEX to override).
