# Release v2.90.0 - Songcatcher Lynx

Released: 2026-10-08

## Highlights

- **Bring Suno songs in as music-video tracks.** Paste a Suno link and PortOS imports the song through the signed-in PortOS Browser, including private songs and songs whose audio file Suno withholds; non-audio downloads are refused and a cancelled import stops its audio extraction.
- **Voice Lab fine-tuning finished.** Fine-tunes show live runs, can be cancelled, and promote a checkpoint; two fine-tunes of one voice can no longer run at once, and a cancelled run stays busy until its trainer exits.
- **Sharper lyric timing.** Words are aligned to the vocal stem with CTC, words landing in vocal-stem silence are flagged, and mix-only alignments go stale once a stem exists.
- **Deep audits that resume.** Deep audits are an extended regular audit with persistent coverage gates, partitioned coverage, and checkpoints that survive cleanup, handoff, and explicit resume; audit fixes land in verified draft pull requests.
- **Better music-video authoring.** Mood-board text notes render into images, local document authoring recovers from dropped or malformed sections and resumes from completed batches, Autopilot adopts production's own final render instead of rendering twice, and a shared camera-movement vocabulary and kinetic lyric type are available to compositions.
- **Character styles and publishing polish.** Loadable Music Video character styles start with Claudia slopcore; the Publish page can mark a platform done without a link and folds finished cards.
- **Models.** Claude Haiku 5.5 joins Claude Code presets, pricing, and model comparison.
- **Safer and steadier.** Host authority is required for application detection, OpenClaw session messages, and Writers Room authoring; probes that ignore SIGTERM settle at their deadline; memory history and replacement links are preserved and CoS memory views stay current after remote changes.
- **A calmer test and CI suite.** Browser fixtures start in bounded phases, Chromium launch stalls are retried, and many timing-sensitive tests on busy hosts and Windows were made deterministic.

## Added

- Importing a Suno song link as a music video's track, including private songs and songs without a downloadable file.
- Voice Lab fine-tuning: live runs, cancel, and checkpoint promotion.
- CTC alignment of lyric words to the vocal stem, with warnings for words aligned into silence.
- Resumable Deep audits with persistent coverage gates.
- Mood-board text notes rendered into images; Autopilot renders its own board notes.
- Shared camera-movement vocabulary and kinetic lyric type for composition documents; loadable Music Video character styles.
- Claude Haiku 5.5 in presets, pricing, and model comparison; the dashboard shows live LLM runs and loaded Ollama models.
- Memory history and replacement links are preserved; audit fixes are left in verified draft pull requests.

## Changed

- Deep is an extended regular audit with historical evidence preserved and bounded assignments that do not shrink coverage.
- Composition preview media loads on demand; the storyboard counts unfinished shots instead of listing each one.
- The Publish page names DistroKid by what it does; maintenance notifications can be dismissed and fit mobile viewports.

## Fixed

- Large music-video overlays stay translucent, hidden footage is flagged, and legacy composition engines upgrade without rewriting authored shots.
- Composition images upload to WebGL through a 2D canvas, and sandboxed footage stays readable for pixel review.
- Lyric hook accents stay readable and have centered zones.
- Full-width pages no longer shift up after an anchor jump; the unsupported Beeper attachment control is hidden; Morse targeting hints stay hidden until an answer is submitted.
- A freshly registered agent is no longer retired by the orphan sweep mid-spawn; explicitly abandoned duplicate agents are reconciled; swarm resumes keep claim authority.
- Startup dependency repair refuses shared worktree links; PM2 global options parse before daemon protection.
- Refused publication admission is distinguished from failed writes; the backup restore refusal message reads cleanly.
- Memory saves are guarded by loaded identity, and memory lists and graphs stay current after remote changes.
