# Release v2.54.0

Released: 2026-08-31

## Highlights

- Eidoverse becomes a first-class PortOS world: managed installs, GitHub-backed world sources, an illuminated eight-district World Design V2, deterministic privacy-safe projections, asset resolution controls, and an immersive management UI now work as one upgradeable experience.
- FableLoom grows into an end-to-end episodic production system with a guided 12-gate workflow, human-drivable approvals, editorial autopilot and self-improvement, playthrough QA, cinematic playback, continuity-aware asset generation, 16:9 delivery, and hosted audience sessions.
- Local visual generation expands across hardware and providers with Wan 2.2 and LTX 2.5 CUDA rendering, FastVideo on Apple Silicon, fal H3 Max handoff, long-form audio-image generation, and capability-aware MiniMax H3 draft decoding and memory controls.
- Character voice production now includes machine-local voice profiles, Qwen3-TTS design, consented cloning and fine-tuning, verified FaceTime controls, and hosted protagonist voice sessions while keeping voice artifacts off federation.
- Brain gains command-palette capture, Spotify and YouTube reference libraries, indexed inbox and link projections, and indexed sync-log paging and compaction for faster access without weakening cross-machine conflict semantics.
- CoS and operator workflows add a programmatic GitHub issue watcher, on-demand task installation, contextual model installation, browser-accessible diagnostic logs, and more reliable review, investigation, and PR-delivery behavior.
- Mobile and long-running workflows are substantially more resilient, including responsive timeline and FableLoom controls, preserved hosted-session credentials, bounded voice and Three.js operations, safer unsaved settings, and video renders that can remain quiet without being killed.

## Added

- Added Eidoverse managed worlds, World Design V2, deterministic PortOS projections, source-owner and transport controls, install-local asset resolution, and hosted world management.
- Added FableLoom production gates, editorial autopilot and self-improvement, playthrough QA, cinematic playback, human-driven episodic visual production, continuity review, canon-bound render requests, and scoped hosted audience sessions.
- Added Wan 2.2 and LTX 2.5 CUDA rendering, FastVideo support for Apple Silicon, fal H3 Max handoff, long-form audio-image generation, and capability-gated MiniMax H3 draft decoding.
- Added machine-local character voice profiles, Qwen3-TTS voice design, consented cloning and fine-tuning, verified FaceTime control, and voice-enabled hosted play.
- Added Brain capture from the command palette, Spotify and YouTube reference libraries, projection-backed inbox paging, and sync-log indexes for pull and compaction paths.
- Added a programmatic GitHub issue watcher, installable on-demand CoS tasks, contextual catalog model installs, Eidoverse setup support for Bun, and UI access to diagnostic process logs.
- Added richer Three.js physical audits for swept curvature and bilateral chirality, plus approved character production packages for Universe workflows.

## Changed

- Rebuilt OpenWorld as a living PortOS village and made Eidoverse the private, upgradeable world surface for an install.
- Reorganized FableLoom production around explicit approvals and exact-input replay, defaulting new delivery to 16:9 while identifying incompatible existing media for deliberate regeneration.
- Retired legacy Hunyuan video support and the generated Socket.IO manifest in favor of supported runtimes and source-derived event inventory.
- Scheduled-task prompt upgrades now distinguish explicit user pins from legacy defaults, and optional instance features can gate their related scheduled tasks.
- Updated Diffusers to 0.38.0 and refreshed supported provider, effort, catalog, and runtime metadata.

## Fixed

- Fixed long-running and memory-intensive video paths so silent renders may finish, MLX cache ceilings are reasserted, LTX frame anchors survive denoising, and FastVideo progress remains portable and accurate.
- Fixed Brain sync and projection handling across stale operations, compaction without peers, crash fragments, restores, and large indexed tails.
- Fixed FableLoom and Timeline layouts across narrow viewports, responsive rails, media previews, graph headers, compact controls, and hosted audience surfaces.
- Fixed voice calls and Three.js polling so deadlines cancel downstream audio and model work, stale results cannot overwrite newer state, and slow successful responses remain valid.
- Fixed hosted-session bootstrap and fragment credentials, notification response contracts, auth-status races, unsaved Settings navigation, disabled model-source noise, and catalog-download fallback behavior.
- Fixed managed updates and installs to preserve lockfiles, submodule state, fork-aware source choices, PM2 ownership, and application port isolation.
- Fixed release and investigation automation so required review outages do not strand otherwise deliverable PRs while CI and mandatory verification remain authoritative.
