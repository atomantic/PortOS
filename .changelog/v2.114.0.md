# Release v2.114.0 - Clockwork Camera

Released: 2026-11-08

## Highlights

- Block a music video in a live 3D Previz with song playback, moving cameras, and a shared world connecting its sets.
- Plan the cast's whole story night, place shots on its clock, and review AI-proposed edits before applying them.
- See coding-app token usage from the apps' own history in one report, with new activity grouped in your configured timezone.
- Scheduled jobs and Brain reviews now follow your timezone and keep their intended timing across daylight-saving changes.
- Deploy panels and shot cards recover after a dropped connection instead of staying stuck in progress.
- Phone controls are easier to tap, and messaging and task lists fit the screen.

## Added

- **Music video Previz:** build and sync timed cuts from shots, pick sets and camera holders, position the cast, and preview the song against live greyboxes.
- Create a shared world with connected paths, indoor, outdoor, or space lighting, and sets spaced by their actual size.
- Draft a story night with stays and walking, running, or riding journeys; scrub its clock and place cameras and cuts within it.
- Choose distinct cast and bike colors, camera movement styles, and a turn toward the person kept in frame; character alternates follow the Story selection.
- Ask AI to propose Previz changes with an inspectable full prompt and a separate review checkbox for each valid part.
- Previz build progress and missing-greybox links make unfinished sets visible.
- The Shell toolbar has an Alt+M action for terminal bindings that are difficult to send from macOS or touch devices.
- Scheduled issue claiming has a configurable grace period for new issues and checks linked work before implementation.
- PR Watcher can leave trusted authors' self-managed PRs alone until their configured inactivity window passes.
- App quality audits include a server-side bugs lane and assess reachable failures against each app's deployment requirements.

## Changed

- Usage combines coding apps' native token histories with estimated PortOS-only work in the standard report, replacing the separate native-history screens and duplicate collection pipeline.
- Coding-app usage includes Codex cache-write tokens and dated Antigravity conversation usage where available; peer freshness follows the snapshot time.
- New usage day and hour buckets use the configured timezone; existing historical buckets retain their recorded dates and hours.
- Greybox drafting supports up to 1,500 parts and checks real-world layout, with clearer street infrastructure and light capture backgrounds.
- Shot stills can include figure blocking alongside a finished set photo plate, with a per-shot switch and accurate reference-limit guidance.
- Local model pickers refresh managed Ollama and LM Studio catalogs when installed models change, preserving catalogs when a daemon cannot be read.
- Updated runtime, rendering, browser, and development dependencies, including aligned shared dependencies across workspaces.

## Fixed

- Weekly and interval jobs no longer drift to later weekdays after late runs, and next-run displays agree with the timer across daylight-saving transitions.
- Brain daily digests and weekly reviews use the timezone configured in Settings.
- Deploy progress follows the correct run after reload or reconnect, refuses duplicate operations, and keeps completed runs finished despite late messages.
- Shot rendering status reconciles after reconnect or restart, and a stale Stop response cannot clear a newer render attempt.
- Failed sheet renders stay discoverable after navigation, with preview and recovery of retained originals.
- A paid Topaz upscale survives bounded transient status-check failures while processing continues.
- Shot edits renumber default labels and remove stale catalog image picks while preserving custom labels.
- Gmail sync and Takeout imports avoid counting the same email twice, preserve each connected account's copy, and retain ambiguous legacy matches.
- Spotify history imports and live sync recognize the same play even when their timestamp precision differs.
- Goal scorecards include every event in their four-week window on busy installs.
- Life Calendar deletion protects against double clicks, shifting rows, and stale reads restoring removed activities.
- Tribe saves preserve last-contact updates made by background sync while the form was open.
- Apple Health XML imports settle from the upload response even when a completion event is missed, and ZIP results include clinical records.
- Time Capsule snapshots include genome markers from their current store.
- Database restores remove retired usage tables and identify the offending object when preflight refuses a dump.
- App standardization creates one backup per run and refuses a second run against the same repository.
- Launch in Shell waits for shell readiness before sending the provider command.
- Local Persistent Mind setup only pins an installed model and accurately reports unavailable model catalogs.
- MOSS model downloads display real file and byte progress instead of missing counters.
- iMessage panes stay inside phone viewports; CoS Learning task names wrap without truncating the full row.
- Process, app, Quota Burn, drill, backup, and sharing controls have usable touch targets with clearer separation.
- Authenticated Moltbook writes retain their JSON content type.
- Tracker label cleanup recognizes malformed color-bearing labels while preserving valid numeric identifiers and ordinary label names.
