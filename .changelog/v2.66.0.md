# Release v2.66.0

Released: 2026-09-14

## Highlights

- **Decks — a new Create-section designer for playing-card and tarot decks:** Build a deck, render each card from its own prompt, re-render a single card without touching the rest, and see the exact prompt the renderer was sent. Decks federate to peers as a first-class record kind, and poker/tarot aspect ratios are the per-kind defaults.
- **A pinned model that the vendor retired now tells you, everywhere:** The stale-pin audit reaches reviewer model scalars and saved CoS task templates alongside the settings, scheduled-task and per-record pins it already covered. Retired pins are flagged inline at every model picker and raised as a notification card when a catalog refresh rots one — so a review loop no longer spawns a dead model id mid-run.
- **The Persistent Mind can file issues as its queueing lane:** An install with no coding agent attached can now queue concrete work as a GitHub/GitLab issue — durable, reviewable, and claimable later by `/do:next`, a human, or a peer machine that does have an agent. The grant is off by default and scoped to the mind's existing managed-app allowlist.
- **PR review inputs are safer and its verdicts no longer vanish:** Hidden-content and prompt-injection gaps are closed, a listing that GitHub's GraphQL node budget rejected is fixed, and the bug that silently dropped *every* reviewer verdict when the screened-content builders diverged is gone — a dropped verdict is now visible instead.
- **Phone navigation is icon links again, not a dropdown:** Every fixed set of sections — Settings, Models, Digital Twin, Chief of Staff, Brain, and the app/provider/video drawers — collapses below `sm` to icon-only tabs with a scroll chevron, instead of hiding where you are behind a form control. Accessible names are unchanged.
- **Port labels are attributed to the app that owns them:** Saving the PortOS app record could rewrite a sibling daemon's port to one the API server already held. Labels now resolve against the app's own process surface, a cross-process collision is rejected before any write, and the read and write paths share one rule.
- **The local image runtime is reported the same way on every surface,** with a one-button fix, and the default local render model is configured in Settings instead of a hand-edited `settings.json`.
- **Restores survive long scans:** The restore rsync idle deadline scales to the largest in-scope file, and a `--checksum` scan keeps talking so the watchdog can't kill it mid-verify.
- **A Shell session that had hosted a TUI no longer floods its own prompt** with replayed cursor-position reports (`56;3R56;3R…`) on every re-attach.
- **The project ethos is documented** — digital-mind individuality and the custodial contract, in `ETHOS.md`.

## Added

- **Decks**: a Create-section designer for playing-card and tarot decks, with per-kind aspect-ratio defaults and a per-card re-render button.
- Card decks federate to peers as record kind `deck`.
- The Persistent Mind gains a default-off `fileIssues` grant plus `issues.list` and `issues.file` tools, scoped to managed apps whose resolved tracker is GitHub or GitLab. Filing requires both dispatch axes and stamps persistent-mind and planner attribution labels.
- Managed apps can commit their quality snapshot to `.quality.json`; PortOS now publishes its own through that same managed-app publisher instead of a PortOS-only second path.
- `GET /api/image-gen/:filename/variants` resolves original-vs-cleaned lineage server-side, so the lightbox toggle works from either end and on pages whose list never held the copy.
- A notification card is raised when a catalog refresh retires a pinned model.
- `ETHOS.md` documents the project ethos: digital-mind individuality and the custodial contract.
- `preflight-` is registered as a task-id prefix, so a preflight run's progress card advances past step 1.

## Changed

- The default local render model is configured in Settings rather than `settings.json`, and the Universe Builder resolves its render config through the same install ladder.
- The local image runtime is reported identically across every surface, with a single button to fix it.
- Deck and pipeline surfaces show the prompt actually sent to the renderer — in the deck card preview and in lightboxes opened from pipeline, music-video and deck pages.
- A deck's render model resolves from the install pin instead of the Pipeline form's sticky state.
- Disabled deck prompt/render buttons explain why inline instead of hiding the reason in a tooltip.
- The FLUX.2 venv requires Python 3.10+ and surfaces pip failures instead of reporting them as "connection lost".
- Codex quota exhaustion is treated as benched rather than "needs setup".
- Settings-backed model pins share one settings-path writer, one provider-id coercion, and one provider-name resolver.
- `withUnlistedOption` is extracted and the stale-pin select copies collapse onto it, including VoiceTab's remaining five.
- Sidecar refresh honors its key as a full re-read, and only unhydrated sidecars are fetched.
- Quality actions are styled as buttons, with table cell padding restored.

## Fixed

### Ports and app records
- Ecosystem port labels are attributed to the owning app rather than the first process that declares one — saving the PortOS record no longer rewrites a sibling's port to the API server's. The primary process resolves in config order, role-suffixed siblings are ignored, and a cross-process port collision is rejected (422 `PORT_COLLISION`) before any write.

### PR reviewer
- Hidden-content and prompt-injection gaps in PR review are closed, and the hidden-content diff scanner loads lazily.
- A self-closing `<Icon aria-hidden="true" />` no longer fails the preflight closed. The hidden-markup rule read the next 4,000 characters of unrelated diff as that icon's inner text, so an ordinary comment two functions away could satisfy the abuse pattern and get a clean PR refused as hidden model-directed content. The narrowing recognizes a trailing slash as self-closing only where that syntax is real — a void element or a JSX component — because HTML and GitHub-flavored markdown both ignore it on an ordinary tag.
- A PR listing rejected by GitHub's GraphQL node budget now succeeds.
- Every reviewer verdict was silently dropped when the screened-content builders diverged; the boundary is simplified and a dropped verdict is now visible.
- The PR link stays on the content-mismatch notification.
- Pull-request action buttons no longer wrap text or collide with their icons.

### Persistent Mind and Chief of Staff
- Self-wake is hardened against invented user intents — small local models were reading schema examples and life-logging tools as implied user requests.
- Life-logging voice tools are kept out of the Persistent Mind.
- The duplicate-issue check no longer refuses a file because an existing punctuation-only title normalized to the same empty key.
- New mind recipes are seeded on `catalog.search`.
- Stale `.agent-done` sentinels are swept out of agent workspaces.
- A description line in a legacy `TASKS.md` no longer mints a runnable task, and a recovered user row is withheld from the unattended spawn in both engines.

### Shell and terminals
- A Shell session that has hosted a full-screen TUI no longer replays that TUI's cursor-position queries into the prompt on re-attach. Response-soliciting sequences are stripped from the replay buffer only; live output is untouched, so a running TUI still gets its answers.

### Backup and restore
- The restore rsync idle deadline scales to the largest in-scope file, and a `--checksum` restore scan keeps rsync talking so the watchdog can't kill it.

### Media
- `agy` image generation no longer fails on a retired shipped model id.
- The FLUX.2 venv directory is derived with `dirname` instead of a separator-specific regex.
- Three deck-federation defects found in local review are fixed.

### Managed apps
- Saving a document without changing its bytes returns `noChanges` again instead of a 500, when the app's checkout has unrelated dirty files. The no-op check is now scoped to the document, matching the scoped commit below it.

### MeatSpace POST
- The estimation drill tells you how precise to be.
- The Morse verdict stays on screen long enough to read, with the answer still visible.
- An applied-numeracy answer is accepted without restating the unit.
- Enter no longer advances past a scoring failure, which discarded the unscored answer and scored the drill one response short.

### Documentation
- `AGENTS.md` points at the file that actually declares `NAV_PRESENTATION`, and the API tool contract's tool counts match the runtime registry again.

### Tests
- A racing Stills-tab query in the `VideoTimelineEditor` suite is fixed; the release-snapshot reader is asserted as called rather than only path-matched; `decks.js` is mocked in the `tombstoneGc` unit test; the five ImageGen suites share one page-mock scaffold; recipe fixtures retarget to `catalog.search`; and the `.quality.json` path is joined so the Windows shard passes.
