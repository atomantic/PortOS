# Release v2.75.0 - Pixel Phoenix

Released: 2026-09-23

## Highlights

- Code Animation can turn a universe's visual style into animated scenes, with provider choice, reusable briefs, and a gallery that keeps finished work.
- The Shell page gains an iTerm2 view that stays attached through reconnects and session switches.
- More controls work well with a keyboard and assistive technology, and CoS avatars respect reduced-motion preferences.
- Mood boards can import photos and video from X posts, while Universe pages can import Markdown.
- Model comparisons cover more frontier models, and provider setup is easier to understand and share across CLI and TUI modes.
- Hosted playback, microphone capture, and model-runtime wakeups recover more reliably from interrupted or failed work.

## Added

- A Code Animation workspace for drafting universe-styled animations, choosing a provider, writing a brief from a universe's material, and browsing saved work.
- An iTerm2 view in the Shell page, with session-aware reconnects.
- Photo and video imports from X posts into mood boards, plus Markdown imports into Universe pages.
- Frontier-model comparisons and comparison data sync from OpenRouter and Epoch AI.
- Provider route details and clearer service groupings for composing AI presets.
- Quality-category sorting for managed apps and a second Add task control beside the queue position selector.

## Changed

- Provider settings are shared between CLI and TUI modes, and provider-specific model access is respected by model selectors.
- Dashboard widgets adapt to their grid cells, and narrow pages reflow more cleanly.
- Brain link movement uses keyboard-friendly interactions with clearer announcements.
- Notifications remain available while hovered or focused, and Undo has a keyboard path.
- Hosted episode changes and inference wakeups are coordinated so stale work is less likely to take over an active session.

## Fixed

- Hosted and guest microphone capture is released after startup failures, episode changes, unmounts, and normal session release.
- Hosted playback now cancels stale turns and keeps its session attached to the episode that is actually active.
- Shared process logs reconnect cleanly, and app operations no longer apply completion callbacks to a different app.
- Daily-log writes are serialized so overlapping updates do not replace one another.
- Accessible names remain visible when controls adapt to screen size, and keyboard focus stays usable in shell, goal, and issue controls.
