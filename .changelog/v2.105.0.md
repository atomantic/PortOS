# Release v2.105.0 - Scene Otter

Released: 2026-10-26

## Highlights

- Plan environments with editable greybox layouts, starter scenes, camera shots and optional figures, then use saved shots to guide music-video images.
- Create images directly from creative cards with their universe context and canonical references, and edit shared catalog entries consistently across Casting and Universe Cast.
- Inspect clearer video continuation choices and saved segment receipts, with experimental H3 history adapters and opt-in LightX2V profiles.
- Open creative profiles before loading their media and history, reducing the initial data needed to start editing.
- Approve and revoke Tailcat devices while keeping remote desktop access on the private companion connection.

## Added

- Greybox scenes support manual layout editing, AI-assisted creation and editing, Blender GLB attachments, saved cameras, shot figures and a built-in guide.
- Saved primitive-layout shots can be rendered without an open viewer, with an explicit action to recapture all shots and visible partial progress.
- Creative cards offer contextual image generation, and character sheets use visible canonical references while preserving explicit prompt overrides.
- H3 includes pin-verified video-history adapters for CUDA and MLX plus optional LightX2V profiles; automatic temporal continuation remains unavailable pending paired hardware validation.
- A2V motion and detail adapters have separate user LoRA strength controls.
- Design quality audits can inspect rendered pages alongside UX audits.

## Changed

- Creative catalog editors share canonical entries, explicit universe ownership and linked usage; cross-universe forks preserve provenance with separate identities.
- Creative profiles load their selected cover first, media when its tab opens and history on request, with usage loading asynchronously.
- Music videos can hide automatic lyric overlays while retaining aligned lyrics for planning and authored typography.
- Local sprite loops return to their idle anchor, and verified Metal watchdog recovery settings can be reused without learning degraded profiles.

## Fixed

- Saved storyboard frames remain tied to the paused preview, decoded footage and exact visual revision during capture.
- Greybox rendering replaces stale reference captures, preserves selected shots and figures, restores viewport sizing, and keeps controls responsive.
- Newly generated library and casting covers update immediately, replacement Blender models stay selected after refreshes and remounts, and newer card details appear even when the visible list contains the same items.
- Catalog usage can be retried after a failed live refresh.
- Explicit H3 MLX history input aligns audio to video timestamps and rejects incomplete or discontinuous audio coverage.
- Catalog covers fall back to reference sheets, canonical image selection stays visible, and archived portraits stay out of sheet identity fallback.
- H.264 exports require an ffmpeg installation with the necessary encoder, with actionable errors when it is unavailable.
- H3 adapter layout follows verified metadata rather than filenames; copied speed adapters retain their sampler identity, and live memory admission is enforced.
- Tailcat retains admitted sessions when device policy is unchanged and enforces revocation when access changes.
- Agent prompt submission waits for Codex paste output to settle within a bounded budget.
- Completed agent delivery and checkout retirement retain validation evidence, reconcile existing receipts, and preserve uncertain or unique work.
- Windows Git cancellation contains and settles owned helpers before releasing mutation or cleanup authority.
- Test infrastructure improves process settlement, Windows portability and source-scan reuse while retaining regression assertions and deadlines.
