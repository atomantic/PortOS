# Release v2.98.0 - Guarded Harbor

Released: 2026-10-19

## Highlights

- **Safer host control:** Browsing host directories and naming a host path PortOS reads or runs against now require operator authority, and Tailcat ingress callers that arrive over the loopback hop are refused host control. The agent runner rejects browser-origin HTTP and Socket.IO traffic while retaining native client access. Untrusted text can no longer leave its origin or escape its prompt fence, and model-authored plan fields are contained before they reach a repository.
- **Backups and migrations that survive restores:** Folder restores flag snapshots that predate applied migrations, a pre-split snapshot's Chief of Staff settings are recovered (also on a repeat restore, and left alone when a transfer fails), and unreadable or invalid manifests cannot consume healthy backup retention slots. Legacy file restores that would be ignored by database import markers are refused before transfer. Retired migration 428 cannot remove peer-hosted collection links or covers, including with a rebuilt ledger. A pre-May-2026 migration ledger is adopted on every run, orphaned migration temp files are cleaned up, and the Data Manager classifies the legacy migrations folder.
- **Editors protect unfinished work:** Metadata saves preserve newer prose, draft switches and exercise promotion cannot overwrite a different draft, and failed timeline saves retain edits and guard navigation until a retry succeeds or the writer explicitly discards them.
- **Mood boards:** Upload images and videos directly with safe retries, pins come first, board tools live in one rail with a multi-line prompt field, and the phone tool sheet closes with one step back.
- **Media and rendering:** Runway joins as a paid video renderer, queued renders hold for a backend whose quota says when it resets, superseded music-video renders are cleaned up while referenced finals and posters are retained, and deleted media goes to the OS recycle bin and shows file sizes. LoRA effects now apply correctly on quantized and block-streamed LTX renders, and every applied LoRA is recorded by source and strength.
- **Chief of Staff agents:** Agents hand verified PR heads and pending CI to a merge coordinator and stop, GitHub auto-merge handoffs are verified, held checkouts are retired only under a scoped, archived release, and reconciliation preserves linked worktrees and reports retained work. Archive capture preserves exact Git index bytes without a diff refresh racing the snapshot.
- **Catalog and audits:** Paired owners share canonical catalog identities with recoverable consolidation, Casting, Environments and Objects pages sit over the catalog, audit lanes rotate their slice and learn what became of their filed issues, and an upgrade-rehearsal lane runs migrations and a backup restore in scratch installs.
- **Faster, steadier CI:** A green local pregate receipt is attested on the pushed head so CI skips stages it already proved, a content-addressed test memo skips test files whose inputs already passed, and Linux containment and prompt-history jobs run only when their inputs change.
- **Platform polish:** Kestrel Neon is the default theme for new instances, an Apple Silicon MOSS Image Swift runtime preview was added, Windows `.cmd` shims no longer expose agent prompts to cmd.exe, and the server no longer crashes with EPERM when git prunes a watched refs directory.

## Added

- Runway video renderer; direct mood-board media upload; OS-native media recycling.
- Pending-merge coordinator handoff for agent PRs; scoped release of held checkouts.
- Upgrade-rehearsal audit lane; per-run audit slice scoring and rotation.
- Pregate attestation and content-addressed test memo.

## Changed

- Host directory browsing and host-path inputs require operator authority.
- Kestrel Neon is the default theme for new instances.
- Many long functions split into named steps (music-video gates, CoS adapters, Tailscale setup, image-gen argument builders).

## Fixed

- Backup restore, migration ledger and Data Manager edge cases.
- Browser-origin access to runner transcript and control routes.
- Draft-switch, metadata-response and timeline-save races that could lose edits.
- Git index preservation during checkout archival.
- Music-video render cleanup, cancellation and retention races.
- Many flaky or Windows-only tests and import-reach scanner edge cases.
