# Release v2.70.0

Released: 2026-09-18

## Highlights

**AI Providers is now a composed model, not a list of records.** A harness (Claude Code, Codex, OpenCode, Antigravity, …) plus a method plus a service is a runnable combination on its own — you no longer have to save a provider record before you can use one. Every provider picker in the app shares one preset-first selector with a harness-grouped list and a "Custom combination…" compose flow, and the page itself is now three views: Presets, Harnesses and Services.

**Local model weights are remembered instead of re-scanned.** Models > Status loads a manifest PortOS keeps as it installs and deletes weights, so "what have I downloaded?" no longer walks tens of gigabytes of disk on every visit. A Rescan disk button reconciles anything installed or removed outside PortOS.

**The llama-server launcher can load a vision projector.** Multimodal GGUFs keep their vision tower in a separate sidecar; the launcher now downloads it, shows its status, and passes it on the launch line — so a multimodal preset no longer starts quietly text-only. Ternary Bonsai 2 27B ships as a new drafter-free preset.

**Autobiography's daily story prompt is back, and configurable.** The nudge offers three ideas from different themes rather than one assignment, you can write against your own question instead of a bank prompt, and stories can be scored against a seven-move storytelling rubric on request. The feature can be switched off entirely, and its reminder time is a separate opt-in.

**Chief of Staff recovers agents that stop mid-task.** A TUI agent that narrates its next step and then goes quiet gets "continue" typed into it after three silent minutes, up to three times, and is badged Stalled if it never resumes — instead of holding an execution lane forever.

**Queue counts stopped double-counting.** A task being spawned briefly appeared as both pending and active on the dashboard widget, the System Resources cards and the health widget; all three now read one settled count, and "N queued" in the health widget no longer always renders 0.

**Catalog ingest stopped turning real people into fictional characters.** Pasting an autobiographical passage came back with `MOM`, `DAD`, `NARRATOR` because the extractor never told the prompts what it was reading. Factual sources now suspend the invent-a-role rules and keep a person named by relation as "Mom".

**Model comparison syncs two more leaderboards.** SWE-bench and LiveCodeBench join Artificial Analysis as automated benchmark sources, selectable from the sync modal. Comparison charts and the FableLoom graph both gained drag-to-pan.

**A pull request can now be merged from PortOS without spending an agent.** The Apps PR/MR tab has a plain Merge button with an inline confirm carrying the merge method and a delete-branch box — and it refuses to delete a long-lived source branch.

**CI failures name themselves again.** A job that fails cancels its siblings, which used to leave every check reading "cancelled" with no cause and send people to the billing dashboard. The fail-fast step now annotates the run with the job, shard and failing step before it cancels.

## Added

- Composite provider ids (`harness.method@service`) resolve through the same path a saved preset does, with per-harness enablement, a credential-bootstrap table and a compatibility matrix of every harness × service pair.
- Derived presets: a saved preset can name the service it runs on and re-materialize its connection details from that service on every save, so an edit in one place reaches every preset built on it.
- "Save as preset" from the compose flow, and a one-click conversion offer for legacy records that can be re-derived exactly.
- AI Providers page: Presets, Harnesses and Services views, a service add drawer, explicit catalog refresh, and delete gated on zero presets.
- `--mmproj` vision-projector support in the llama-server launcher, with on-disk status, download progress, removal and orphan-partial cleanup for the sidecar.
- Ternary Bonsai 2 27B launcher preset (PQ2_0, 262K context), with measured Apple Silicon throughput and a note on why stock llama.cpp cannot run it.
- Downloaded-model manifest behind Models > Status, covering the Hugging Face cache, LoRAs, Ollama and LM Studio, with a Rescan disk reconciliation.
- Autobiography as a switchable instance feature with an opt-in daily reminder time, a three-idea prompt menu, user-supplied story questions, and an on-request storytelling-rubric score.
- SWE-bench and LiveCodeBench benchmark sync sources on the model comparison page, with a source selector in the sync modal.
- A Merge button on the Apps Pull Requests tab that runs the forge's own merge with no agent in the loop.
- Drag-to-pan on the FableLoom graph and on stretched comparison charts.
- A "continue" nudge and Stalled badge for CoS TUI agents that stop mid-task.
- A warning on the CoS task form when the pinned model cannot call tools.

## Changed

- Every provider picker in the app — 29 of them — now renders the shared preset-first selector, so the harness-grouped list, compose flow, unavailable-pin rendering and effort ladder behave the same everywhere.
- The mood boards page is now cards with cover and item thumbnails.
- The duplicate Models > Harnesses page is retired; version, update, remove and model refresh all live on AI > Harnesses.
- The CoS activity heatmap and the Eidoverse activity district read live agent history instead of a derived file that only changed when someone pressed Refresh; the CoS Productivity page is removed.
- The Eidoverse Agent Foundry no longer raises attention for an ordinary queued task, and does raise it for a task waiting on a person.
- The two shipped provider sample files are generated from one source and reconciled, closing 17 records' worth of silent drift between a fresh install and the toolkit fallback.
- Release-note-worthy provider values that were missing from a fresh install's seed (Claude Code headless arguments, context windows for four CLIs) are now present.

## Fixed

- A queued config write could erase the autobiography reminder settings, silently turning the daily prompt off.
- The Digital Twin section strip kept showing the Autobiography tab after the feature was switched off; a reminder-time edit was lost when navigating away by ⌘K or voice, and a rejected save left the typed time on screen.
- A model run killed by a cloud gateway recycling an idle connection (an HTTP/2 GOAWAY) is retried instead of failing the run and opening an investigation task.
- Pi TUI agents never submitted their prompt, because PortOS did not recognize Pi's paste chip.
- Saving a provider with no fallback started failing after the provider-id grammar tightened; "None (use system default)" works again.
- One stale service row no longer takes down the whole provider composition surface.
- Antigravity's per-model effort rungs were silently empty and fell back to the harness default.
- A composed route no longer writes the previous provider back over itself when the caller merges the model change.
- A cancelled drag left the next unrelated click on the same surface silently swallowed.
- The activity calendar clamps its requested week count, so a malformed request cannot exhaust memory.
- Manifest reconciliation no longer prunes a model the backend positively listed but the disk scan could not corroborate.
- A preset pinning a filename by hand can no longer fetch a vision sidecar into the language-weight slot.

## Internal

- A tree-wide guard now fails the build on any newly hand-rolled provider picker, so the shared selector cannot be bypassed.
- The daily-reminder scheduler — cron registration, feature gate, missed-slot catch-up and timezone reconcile — is shared between MeatSpace POST and the autobiography prompt rather than duplicated, so the next fix to that logic only has to be made once.
- The two ways PortOS merged a pull request are folded into one, so authentication, timeouts and failure reporting behave the same from every surface.
- A shared wait-until-enabled test barrier replaces more than twenty hand-rolled copies, and several client tests that could pass for the wrong reason now settle on what actually rendered.
- The agent instruction files were compressed onto the documents they link to, and the issue-label vocabulary now lives in exactly one place.
