# Release v2.67.0

Released: 2026-09-15

## Highlights

- **Managed apps can run under a second GitHub account:** Apps whose code lives under a different account now list issues and pull requests with that account's credentials, claim issues against the right forge identity, keep existing label metadata intact on sync, and survive a misconfigured account field instead of crashing the editor.
- **Free NVIDIA endpoint for trying models:** A new gateway exposes NVIDIA's free models with side-by-side comparison coverage, so you can evaluate a model before spending provider credit.
- **Local model catalog refresh:** The curated catalog adds Mistral Small 3.2 24B and maps Qwen3-Coder 30B for LM Studio, and a local image-model pin now follows you through every model picker instead of being dropped on some surfaces.
- **Claim an issue and let CI merge it:** Direct issue claims now carry a merge-on-green policy, and the spawned run records its hold plus a versioned fingerprint of the PR content it produced.
- **Provider usage cards show your plan,** and the app issues page gains a filed-by filter.
- **Deck cards show their full art:** Playing-card and tarot thumbnails are no longer rounded or cropped, and each card can toggle between render versions.
- **Remaining hand-rolled sub-navs become tab pills,** and the Chief of Staff avatar is no longer clipped by its canvas.
- **Google Workspace libraries move to current majors** with the OAuth2 contract they carry pinned and covered.

## Added

- NVIDIA NIM free-endpoint gateway with comparison coverage.
- Second-GitHub-account support for managed apps: per-app forge identity for issue/PR listings and claims.
- Filed-by filter on the app issues page.
- Subscription plan name on provider usage cards.
- Deck card render-version toggling.
- An agent-prompt measuring script that ranks a rendered agent prompt's sections by size.

## Changed

- Local model catalog refreshed with Mistral Small 3.2 24B and a Qwen3-Coder 30B mapping for LM Studio.
- Deck card thumbnails show the full playing-card and tarot art without rounding.
- The leftover hand-rolled sub-navigation bars are converted to tab pills.
- Root contributor guide trimmed, with long-form rationale moved into focused docs.
- The issue-filing prompt is emitted once when the task body already embeds it, including across re-indented embeds.
- A missing script flag can no longer silently swallow the first positional argument.
- PDF library bumps are ignored until the upstream ESM regression is fixed; zod, lucide-react, and the client toolchain move to current releases.

## Fixed

### Managed apps and forge integration

- App issue and pull-request listings authenticate against the app's own GitHub account instead of failing on the wrong identity.
- The claim-issue detector is pinned to the app's GitHub account, and existing label metadata survives a sync.
- A non-string forge account value in the app editor is rejected instead of crashing the save.
- Three defects across the retired-model-pin and forge-issue surfaces are fixed.
- A cloud model pin no longer leaks into the local resolver on deck fallback.
- The autofixer fails cleanly with an explanatory error when the process-manager binary is missing.

### Decks

- Deck card thumbnails render the full art; an aspect-ratio check that failed on sub-pixel canvases now names the missing deck clause.
- Render bookkeeping no longer bumps a federated card's update timestamp, so peers stop seeing phantom changes.
- The accepted duplicate-card trade is recorded in the reconcile documentation.

### Interface

- The Chief of Staff avatar is no longer clipped by its canvas width.
- Google sign-in token refresh is hardened and a refused refresh is covered.

### Tests

- Three wall-clock-sensitive suites (a native-helper compile, a whole-tree accessibility scan, and a real-timer world-reconcile pass) carry their own runner budgets so a contended worker can't time them out; an update-advisory assertion awaits its repo-source call; SSH alias semantics are pinned.
