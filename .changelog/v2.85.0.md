# Release v2.85.0 - Steady Showrunner

Released: 2026-10-03

## Highlights

- **Music videos you can steer end to end:** route each stage to its own LLM, add an optional lyrics review pass, set Suno form options (including Max Mode), retake a song after a stopped or failed run, and pick an Eidoverse Video render style. Review now accepts rendered frames and animatics as evidence in code-only projects.
- **Rich music-video choreography and cards:** media modes with code-authored choreography, art/choreography/animation review before production, comparison and reuse of accepted Code Animation evidence, and detailed project cards with previews on the main page.
- **Eidoverse comes alive:** the runtime now auto-starts at boot and when the feature is enabled, Persistent Minds can resume an open peer visit on their next wake, and bounded local scene inspection is exposed.
- **Persistent Minds can delegate:** evaluated tool-free model delegation lets a mind hand work to another model.
- **Far fewer lost edits:** overlapping edits to share buckets, Characters, federated video history, task templates, epigenetic history, Writers Room buffers and goals are now serialized or merged instead of overwriting each other, and goal deletions propagate through federation.
- **Recoverable failures instead of silent ones:** Brain Inbox captures survive rejection with Retry/Edit/Discard, database restores stay fenced until recovery finishes with clearer refusal messages, and CoS health shows failed probes and stale results instead of a false all-clear.
- **Health alerts get a "Resolve with agent" action** in Actions.
- **Tidier pickers:** provider model pickers and preset filters are alphabetized.

## Added

- Per-stage LLM routing and an optional lyrics review pass for music videos; Suno form options and Max Mode; song retake for autonomous runs; Eidoverse Video render style; media modes with code-authored choreography; rich project cards with preview.
- Evaluated tool-free model delegation for Persistent Minds.
- Bounded local Eidoverse scene inspection, and Eidoverse runtime auto-start at boot and on feature enable.
- "Resolve with agent" on health alerts.
- Review of music-video art, choreography and animated evidence before production, and comparison/reuse of Code Animation production evidence.
- Quality snapshot measurements published for releases.

## Changed

- Provider model pickers and preset filters display alphabetically.
- The Git recovery agent publishes pending work instead of stashing it.
- Local pregate bounds its Vitest workers so concurrent worktree gates stop starving each other.

## Fixed

- Brain: Inbox capture stays usable while history loads, rejected captures are recoverable, deep-linked reader edits stay current, and On This Day opens the exact memory or idea.
- Music Video: load failures stay visible with retry, same-title tracks are distinguishable in selectors, stages are revealed above shared review panels, and timeline edits stay bound to the selected project.
- Data safety: database restores stay fenced until recovery finishes, restore refusals are explained, Mind upload markers and pending images survive failed rollbacks, media outcomes are saved before being acknowledged, screenshot uploads never truncate a stored image, and mailbox accounts survive failed reads.
- Writers Room: async format and polish results no longer overwrite newer edits.
- Federation and sync: goals, Character XP histories, taste answers, and unknown entity references merge without dropping independent changes.
- Voice: incomplete model downloads are repaired before readiness is reported, and canceled Piper synthesis is rejected before spawning.
- System health: failed CoS queue and agent-census probes and missing catalog tables are surfaced; auto-restart is recorded only after recovery is verified.
- Eidoverse: stamped dismount geometry, scene completeness across nonspatial acts, and cancellation before song mux are honored.
- Settings and Data Manager storage totals are clearer; database sync explains replacement and startup requirements first.

## Internal

- Many browser and unit tests were made deterministic (Inbox, Goals, Windows paths, client timeout budgets), and several private helpers were kept module-private.
