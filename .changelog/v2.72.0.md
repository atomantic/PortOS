# Release v2.72.0

Released: 2026-09-20

## Highlights

- Review queue actions now remain available through triage and archive transitions.
- Product recommendations now enter the review queue for consistent follow-up.
- Scheduled task configuration is easier to manage from one consistent control surface.
- Assigned GitHub issues can become Brain threads, with source-closed threads completing from the main action surfaces.
- Managed-app pull requests can be prepared through an agentic workflow with safer review credentials.
- Media creation now offers broader prompt analysis, video-model choices, and more reliable local rendering.
- Deck cards show render attribution and support configurable face orientation.
- Stacker News risk decisions now pass through the configured safety review path.
- Agent worktrees share dependencies safely and handle platform-specific paths more reliably.
- React dependencies and review tooling remain compatible across supported environments.

## Added

- Review queue triage state persists across reloads and lifecycle changes.
- Scheduled task controls, Brain issue tracking, managed-app pull request actions, and configurable deck presentation options.
- Additional local video and media-generation compatibility for current Apple and Windows setups.

## Changed

- Product recommendations are routed through the review queue.
- Recovery notices and assigned issue tracking are surfaced through Brain threads.
- Media and provider workflows preserve diagnostics, compatible model settings, and isolated local environments.

## Fixed

- Review queue lifecycle and triage gaps no longer discard available actions.
- Async action states, timeline interactions, claim cleanup, provider streams, and review credential bootstrap handle failure paths more reliably.
- React, video-generation, and dependency-linking workflows preserve compatibility across supported platforms.
