# Release v2.101.0 - Storyboard Compass

Released: 2026-10-22

## Highlights

- **Storyboards, end to end:** A new shared planning board under Create turns a shot into frames with a panel maker, draws beats from a plot summary, keeps a saved recipe library, and fills empty panels in one step. You can play the animatic against a temp track, pin beats to song sections and lyric lines, and copy a song brief. Storyboards also sync between your paired machines.
- **GitHub notifications inbox:** A new inbox on the GitHub page triages notifications with fixed rules, shows only actionable items under Needs you, and offers Assist mode with batched Autopilot, a notification subscription audit and a monthly audit report. GitHub accounts carry trust levels, and unsubscribed threads return when new activity arrives. The notifications check now runs as a System task.
- **Code Animation grows up:** Fork and extend a finished animation, generate audio and a coding-model soundtrack for it, play with a playhead and soundtrack in the preview, delete gallery items, and Record (real-time) saves an MP4 to Media History that plays inline.
- **Node.js runtime from the Update tab:** Show and update the Node.js runtime from Settings, with the boot script and Node pin kept in step. Node 26 is now the preferred line for CI and `.nvmrc`, and PortOS moves to pm2 7.1.0.
- **Failed reads say so:** About 30 more list reads (LoRA training, music library and models, Sharing inbox, JIRA config, ⌘K knowledge search, character reads, org holdings) show an error with Retry instead of looking empty.
- **Usage across instances:** A chart of the rolling 30-day API cost estimate spans every instance.
- **Sturdier agent runs and cleanup:** Branch reconcile retires superseded, merged and orphaned claim checkouts, `.agent-done` sentinels no longer block cleanup, and a claim can iterate with a GitHub/GitLab reviewer alone and resumes when that reviewer answers late.
- **Safer backup restore and sessions:** A restore of a pre-081 backup upgrades its inbox and journals in order, and revoking a PortOS session ends remote desktop viewer tokens and live VNC bridges. Text that PostgreSQL would refuse (split emoji, NUL) is repaired before it is stored.

## Added

- Storyboards board, panel maker, recipe library, plot-summary beats, temp-track animatic and cross-machine sync.
- GitHub notifications inbox with Assist mode, Autopilot, subscription audit and monthly report.
- Code Animation fork/extend, audio, soundtrack, gallery delete and real-time Record.
- Node.js runtime switch on the Update tab.
- Rolling 30-day API cost chart across instances.
- Per-task Stall nudge toggle for scheduled tasks (off by default for do-release).
- Docker containment profile for untrusted install and test runs; upgrade rehearsal covers Postgres backup and restore.

## Changed

- "PR review" on the app PR tab is now "Untrusted:Review".
- Abuse Guard auto-selection prefers a provider whose window fits a PR.
- Routine refusals, holds and fallbacks log to stdout instead of stderr.

## Fixed

- Failed list reads render an error with Retry instead of an empty state across LoRA, music, Sharing, JIRA, ⌘K search and org holdings.
- Music-video renders are no longer blocked by a failed Video Gen status read.
- Imported mood board captions and typed pin captions are no longer promoted into model prompts.
- Retired OpenCode Zen model ids are replaced in shipped defaults and installs.
- Shutdown no longer blocks on the share-bucket watcher; a TUI raw.txt spool no longer reports ENOENT after the final drain.
- Several flaky tests (watch-config restart, scanner snapshot, Windows paths and file locks) were made deterministic.
