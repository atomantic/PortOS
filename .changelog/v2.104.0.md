# Release v2.104.0 - Fast Songbird

Released: 2026-10-25

## Highlights

- **Choose how agents run:** Codex Fast mode and capability-checked execution options are available across agent launches, scheduled work, and code review.
- **Reference-driven video with sound:** Video Gen adds FastH3 Omni, combining a starting image with reference images, previous clips, and uploaded voices to generate video with audio.
- **Exports that travel:** FableLoom adds export preflight and a ZIP handoff, keeps selected exports visible across dialog updates, and preserves finished exports when status responses arrive late.
- **Hear your animations:** Code animation MP4 exports include uploaded audio and verify it through the export workflow.
- **Clearer usage:** Image generation counts can be viewed by week, month, and reset period; Claude subagent usage and media units are included across the fleet.
- **Steadier autonomous delivery:** Completed agent work recovers after its original task disappears, verifies the exact delivered PR head, and retires owned checkouts without losing edits, recovery state, or ownership evidence.
- **Safer maintenance:** Settings adds Data Maintenance for retained LoRA training data, with a fresh preview and explicit confirmation before removal; existing datasets, checkpoints, adapters, configuration, and history survive the upgrade.

## Added

- Codex Fast mode and validated execution options.
- FastH3 Omni reference-to-video generation with audio.
- FableLoom export preflight and ZIP handoff in the app and CLI.
- Uploaded audio in code animation MP4 exports.
- Image generation counts by week, month, and reset period.
- Data Maintenance in Settings and a bounded agent claim-workflow audit job.

## Changed

- Casting, Environments, and Objects are grouped under Catalog in navigation.
- Time Machine backups exclude regenerable build and cache churn, and backup setup avoids repeated administrator authentication.
- Local validation runs its focused structural guards once and explains whether shared dependencies are stale or their links are broken.

## Fixed

- Agent completion and checkout recovery preserve exact delivery evidence, stopped Git operations, resolution edits, shared repository state, and Windows path identities.
- Operator-parked claims stop retrying, expected dispatch holds avoid incident alerts, and audit reservations follow the normal spawn lifecycle.
- Active requests protect managed model daemons from idle and memory-pressure eviction.
- Mood boards accept data URLs and show item-add failures; pinned and recent navigation entries retain their icons.
- Usage period controls wrap on phones, and reset periods reconcile correctly after early recovery.
- Superseded CI runs can recover when an aggregate gate never starts; test process ownership, cancellation, and cross-platform fixtures retain better failure evidence.

## Removed

- New LoRA training, queued training dispatch, and training-only controls; reference-image generation and inference with imported or previously trained adapters remain supported.
