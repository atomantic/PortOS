# Release v2.99.0 - Tightened Hatch

Released: 2026-10-20

## Highlights

- **Peer sync that cannot be hijacked or looped:** Per-peer sharing settings now apply to Brain, memory and catalog pulls, a stuck peer cursor no longer makes pulls loop, peer-pushed bundles are bound to the record they claim to carry (and fail closed on unverifiable owners), peer announcements naming loopback or link-local hosts are refused, and a peer's malformed relay events can no longer crash the server.
- **Media uploads and synced files are screened:** Uploads and peer-synced media whose bytes are an ffmpeg playlist or manifest are refused, including when the manifest sits past a long ID3 tag, and previously stored manifests are quarantined. Federated media input stores are bounded per caller and in total, and the media quota check is serialized with the write and fails closed on a scan error.
- **Credentials and prompts stay contained:** Server secrets are kept out of managed-app, deploy and install child environments, credential-named provider variables are masked even when not flagged secret, Moltworld account ids are masked, and scheduled agent prompts fence upstream commit text and error text. Autofixer repairs are confined (no host Unix sockets or extra writable roots, no user MCP tools) and PR remediation is pinned to the reviewed head.
- **Operator authority where it matters:** Music Video ffmpeg render dispatch, voice and palette Brain capture and image generation, cover-font installs, and driving the signed-in managed browser (and reading its downloads) all require operator authority now. The activity digest only drafts AI narrative on a tool-free provider, and public comments no longer feed epic decomposition.
- **Prototype-key and unreadable-store safety:** Counter maps, memory mastery keys and usage records refuse prototype names, and settings, `.env`, drafts, browser, feedback and similar stores refuse to write over a file that could not be read rather than replacing it with defaults.
- **Eye exams, music videos and media stay in sync:** Eye exams no longer duplicate across synced machines and edits/deletes sync; media collection items removed on one machine stay removed; music-video sync versions are bumped so older peers stop overwriting newer fields; music-video finals pinned to mood boards are kept; Persistent Mind attachments and staged image inputs survive cleanup.
- **Runway text-to-video and a refreshed local model catalog:** Runway gains text-to-video and creative workflow lanes, backend pins for fal and Runway are gated on peer sync versions, and the local LLM catalog adds Nemotron 3.5 Bolt 74B-A9B.
- **Catalog and editor correctness:** Universe canon projections reject stale writes and keep independent edits, catalog conflict clocks stay monotonic, universe drafts and ingredient editors stay bound to the record being edited, stale image picks are invalidated when inputs change, and load failures in Brain deep links, the timeline libraries, Writers Room bibles and universe run history now show a retryable error instead of an empty or "not found" state.
- **Chief of Staff delivery safety:** Claim-run merges are audited for bypassed admission or pending CI, merge-gate evidence is judged as it stood at the merge, fork PR heads and retry branches are preserved, and checkout retirement now recovers initialized, restored and reused checkouts with reviewed metadata evidence.
- **Steadier upgrades and tests:** Upgrades stop reporting untouched shipped prompts as customized, the retired NVIDIA Kimi preset is removed from upgraded installs, boot smokes get kernel-assigned loopback ports, and a pile of flaky tests were made hermetic.

## Added

- Runway text-to-video and creative workflow lanes; Nemotron 3.5 Bolt 74B-A9B in the local LLM catalog.
- Audit of claim-run merges for bypassed admission or pending CI.

## Changed

- Several host-control surfaces (render dispatch, voice and palette capture, cover fonts, managed browser) require operator authority.
- Batched raw transcripts reduce admission journal stalls.

## Fixed

- Local model backends: report error when LM Studio is down in `listManagedBackendModels` so the model catalog and Persistent Mind do not mistake an outage for an empty catalog, and fail `migrateBackend` with an error when the source backend list cannot be read (#12608).
- Goal time blocks scheduled in user timezone instead of server UTC, with proper milestone boundary and undated milestone handling (#12611).
- Peer sync authorization, cursors, bundle binding and relay robustness.
- Playlist and manifest media smuggling; media quota races.
- Credential leaks into child environments, logs and prompts.
- Eye exam duplication, music-video sync overwrites and media removal resurrection.
- Writes that replaced unreadable settings and stores with defaults.
- Silent empty states on failed loads in several editors.
- Checkout retirement and reconciliation recovery paths.
- SuperCollider Docker setup retains and prints the trailing build lines on failure, exposing package or compiler error lines without requiring --verbose (#12613).

## Internal

- Many module-private cleanups, comment-contract fixes, and new tests; quality snapshots refreshed.
