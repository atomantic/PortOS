# Release v2.89.0 - Cinematic Conductor

Released: 2026-10-07

## Highlights

- **Music videos that direct themselves further.** Autonomous runs gain an orchestrated mode that sends flagged sections of the final video back for revision, gets past the art and storyboard gates on its own, waits for Cast & Sets instead of parking, and can resume after a failure, cancellation, or hand replacement.
- **Cinematic Code Animation.** Authored Three.js worlds gain a lens with depth of field, bloom, and a graded finish; Code Animation can study a reference video and offers a three.js renderer with vendored addons.
- **More ways to publish.** Substack joins the publishing destinations; DistroKid, TikTok, X, and Suno draft preparation handle more of each site's real layouts; the publishing kit renders the 9:16 cut natively when the composition supports it.
- **Safer agent and database operation.** Database bootstrap and Docker transfer passwords stay out of process arguments, sign-ins and refused host-control requests are logged, and upgrade migrations no longer risk truncating provider, schedule, or app config on a crash.
- **Memory you can trace.** Each agent run records which memories were injected into its prompt, and memories gain typed links with their own id, type, note, and creator.
- **Reminders for the steps only you can take**, scheduled as Actions tasks, plus Rate cards rendered inline for completed CoS runs.
- **Polish across the app.** Counts read "1 file" and "1 account" instead of "1 files"; stuck buttons, stale search results, and Home Screen preview downloads are fixed.

## Added

- Autonomous music-video runs have an orchestrated mode that returns flagged final-video sections for revision.
- A parked music-video production run can swap its video model and continue from Resume; one Resume covers an interrupted run.
- Autopilot resumes after its production fails, is canceled, or is replaced by hand, and names every storyboard blocker when lyric timing holds it.
- Code Animation offers a three.js renderer, studies reference videos, and attaches references to vision-capable CLI providers.
- Authored worlds can use `ctx.lens` for depth of field, bloom, and grading; worlds that never touch it render as before.
- Substack is a publishing destination; Suno Hook drafts can be filled from the vertical cut; long music videos render across several browsers at once.
- Agent runs record the memories injected into their prompts, and memories support typed links.
- Steps that only the operator can take become Actions tasks with reminders; completed CoS run actions render their Rate card inline.
- Sign-ins, password and session changes, and refused host-control requests are written to the audit log.

## Changed

- Vertical 9:16 exports keep the whole frame over a blurred fill instead of cropping lyrics off, and render natively when the composition lays itself out at that frame.
- Release copy says exactly what goes into a post, keeps hand-written posts, numbers, and links through a redraft, and adds nothing unasked.
- The shot auto-reviewer sees each shot's own prompt rather than the whole-video concept.
- Footage production is refused at start for text-only local video models, and planning generates footage when the brief selects video tools.
- Database bootstrap and Docker transfer passwords no longer appear in process arguments; the PostgreSQL pgvector image is pinned to a verified digest.
- Claude providers that pin a permission mode no longer also receive the bypass flag.

## Fixed

- Cast & Sets tolerates null, boolean, single-string, and object field answers, and a skipped sheet's world is ignored when drafting shots.
- Qwen-Image 2.1 on Apple Silicon no longer fails every generation with reference images, and a missing private encode hook warns instead of failing loads.
- Storyboard prepare no longer crashes once scenes are planned; reminders are never dropped when a timer wakes early.
- DistroKid, TikTok, X, and Suno draft preparation survive modal changes, fixed-artist accounts, and look-alike songs.
- CoS task files are written atomically, archiving a stale agent no longer corrupts its recording, and apps.json writes are serialized so concurrent edits no longer revert each other.
- A page on any loopback port is no longer treated as same-origin to the PortOS API.
- Singular counts read correctly across toasts, backup, wiki log, and messages; failed saves no longer leave buttons disabled; slow searches no longer overwrite newer ones; iOS Home Screen previews no longer stick.
- Logging a calendar event on a Tribe person twice no longer duplicates touchpoints.
