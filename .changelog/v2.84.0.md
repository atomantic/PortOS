# Release v2.84.0 - Sandboxed Songsmith

Released: 2026-10-02

## Highlights

- **Fully autonomous music videos:** start from one prompt, pick the autopilot LLM, choose a local song source when Suno is unavailable, schedule runs, and watch live output with visible cast references and submitted prompts.
- **Contained Code Animation production:** workers now run in an enforced sandbox (including bubblewrap on Linux), with bounded stage runs, a visual reviewer pass, a checked Blender adapter proven on a real Blender runtime, and offline stereo soundtracks.
- **SuperCollider in the Music Designer:** managed runtime and setup, contained cancellable renders, preview, and Save as take with provenance.
- **Suno import you can trust:** completed songs are exported through the browser, verified as audio, bounded in size, and diagnosed clearly when a creation request is not accepted.
- **Safer host control:** media authoring, runtime installers, motion skills, and Autofixer controls now require operator authority.
- **Sturdier data handling:** backups no longer overwrite recovery points, legacy record splits and memory-graph migrations fail safely, Windows atomic replacement preserves the original file, and Brain graph and listing work is faster.
- **Polish and accessibility:** larger touch targets, reduced-motion tab scrolling, a command palette that fits short viewports and no longer closes the drawer beneath it, and labelled direction editor inputs.

## Added

- Autonomous Music Video runs from a single prompt, an autopilot Schedule form, existing mood-board option, LLM choice with visible TUI runs, second-render Suno default, local song source, and ~3 minute lyric targets.
- Reusable code character definitions with a previewed sheet and editable direction for procedural Cast & Sets, and a procedural Cast & Sets check-in for code-first projects.
- Code Animation stage runs (measured style frame, pilot, inspection, repair, final render) with a Production UI and optional visual reviewer; sandboxed workers; a checked Blender adapter; revision-bound offline soundtracks.
- SuperCollider audio integration: managed runtime, `setup:supercollider`, Music Designer language, render jobs, preview and take provenance.
- Confirmation before deleting a Music Video project.

## Changed

- Autonomous-run output is visible in the Music Video view, replacing the duplicate stage strip.
- Persistent minds size their output reserve and wakes to small local model windows and honor Ollama context sizes.
- Provider code-review verdicts are validated, and configured reviewers work without enforced isolation.

## Fixed

- Suno: unrelated workspace rows are no longer accepted as submitted songs, Advanced creation uses current form controls, and decoder runtime is capped.
- Backups: fresh snapshots never overwrite recovery points, database tools bind to the checked database, and TLS trust survives temporary certificate bundles.
- Settings restores serialize with pending mutations, and saved CoS schedule execution fields are validated.
- Native database and Docker configuration are applied before readiness is reported; quoted `.env` values parse identically in PM2 and setup.
- Review history, Actions, Instances and storage snapshots stay usable while loading or when unavailable, with explicit retry.
- Writer LLM pin survives saving before providers load; cognitive drill pair constraints and POST drill results match what ran.
- Command palette Escape, Tab focus forwarding, narrow FableLoom cards, mobile app actions, and the launch video tab are corrected.
- FTP listing denial of service in a bundled dependency is patched.

## Internal

- Many tests were made deterministic (relay sockets, Universe Builder hooks, Windows paths, benchmarks), CI gained ffmpeg and a palette browser driver, and unused modules were removed.
