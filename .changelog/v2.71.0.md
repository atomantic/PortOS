# Release v2.71.0

Released: 2026-09-19

## Highlights

**PortOS can now answer a yes/no question with a local model instead of a provider call.** A new decision scorer (jev) takes a statement plus a fixed set of answers and returns which one holds, with a confidence margin — and refuses to pick when the top two are too close. The issue watcher, message triage and forge maintenance each route their closed-set decisions through it before falling back to the chat model, so the overwhelmingly common "nothing to do here" answer stops costing quota. It ships off by default, and a shadow mode lets you watch it agree or disagree with the chat model on real traffic before switching anything over.

**"Does this change advance what the project said it was for?"** A Check scope button on an issue or pull request scores it against the repository's own PRD.md and GOALS.md and prints the clause it scored against. It is advisory on purpose — no auto-close, no gating label, no blocked agent — and an operator can optionally train a small project-specific head on their own forge history so it learns this codebase's notion of in-scope.

**A Persistent Mind can leave the machine it grew up on.** Chief of Staff > Persistent Mind > Settings seals the identity, personality, playbook, model policy and eligible memories into one passphrase-encrypted `.portos-mind` file, and the import half opens it with a per-group keep-mine or use-imported choice. Applying is never a merge: half of one personality and half of another is a third one nobody authored. Capability grants and the enabled flag deliberately stay home — importing a Mind must not be the thing that starts one.

**The Mind now keeps a journal of what it decided.** Beyond flat memories and sealed rollups, there is a third shape: typed, individually addressable entries for what the mind decided, committed to, is still asking, and is watching — with supersede and resolve as first-class operations. When you change your mind, the old belief stops being quoted as current instead of sitting beside the correction and outranking it.

**Brain gained Threads — the open loops you are on the hook for.** A tracked topic with a status, a next action, and links to the PortOS records and external items that belong to it, with a full tab at `/brain/threads`, an Open Threads dashboard widget, and thread results in unified search and ⌘K. One shared (kind, id) registry now backs every "this record links to that one" chip in the app.

**Eidoverse promotion became two-way and provably about the thing it ships.** A promoted foundation's resilience evidence is now replayed from the foundation's own body rather than from whatever module its author typed in — naming a shipped demo fixture used to be enough to clear the gate. Promotion can also be withdrawn: a retraction propagates to every peer by tombstone, so a body an author later regrets is recallable. Inherited foundations gained two real verbs — read the body, and adopt it, disarmed, with a derived-from edge that survives re-installation.

**A reality universe for factual capture.** Every universe used to be fiction, so a voice memo or journal entry got extracted through a story lens. Universes now carry a factual flag that federates, a seeded "Reality" world ships with it set, and catalog ingest binds committed ingredients to a chosen universe instead of leaving them unlinked.

**Model runs stopped dying silently at five minutes.** A secondary backstop in the prompt runner re-imposed the wall-clock ceiling that the streaming fix had removed — and killed the run as if a human had pressed Stop, so nothing benched the provider and every produced token was discarded. Sixteen persistent-mind runs on this install ended between 301.9s and 302.0s before this was found.

**Usage meters stopped showing another machine's old reading as this moment's number.** A federated peer's stale scrape no longer ends the poll or stands in silently; a window whose reset already passed is dropped rather than rendered as a live meter, and staleness is now judged against the window's own period server-side instead of a flat client-side hour.

## Added

- jev: a local entailment scorer with its own virtualenv, four-stage installer, loopback sidecar (started on first use, never at boot, reaped after ten minutes of idle) and a Models > LLMs panel. Abstention is the contract — it refuses to pick rather than guess.
- Closed-set decisions for the issue-watcher reply gate, message triage (action and priority) and forge maintenance disposition now route through the scorer, with the chat model as fallback and a per-source `off` / `prefer` / `only` mode that defaults to today's behavior.
- Shadow mode: while a source is off, PortOS asks the scorer the same question after the chat model answers and records counts only — no premise, body, comment, diff or verdict.
- "Check scope" on an issue or pull-request row scores the change against the repo's PRD.md and GOALS.md, naming the clause it scored and abstaining on a hair's separation.
- Optional project-specific scope-adherence head trained offline on this install's own forge history, gated on beating both the stock classifier and the majority class on a held-out gold set, with the corpus builder refusing a contaminated split.
- Persistent Mind bundle export and import: passphrase-encrypted (scrypt + AES-256-GCM), per-group keep-mine / use-imported choices, additive memory merge, and named refusals for an unsupported container, a damaged file or a wrong passphrase.
- Mind decision journal with append / supersede / resolve, source-grounded per operation, surfaced as Mind > Journal with retired entries collapsed behind a toggle naming what replaced each.
- Progressive tool exposure for the Persistent Mind: a small always-on core plus family-scoped `tools.activate`, with a turn-scoped retention lease and an escape hatch for sending every schema.
- Brain `threads` record type, `/brain/threads` tab, Open Threads dashboard widget, thread search in unified search and ⌘K, and a shared `(kind, id)` ref registry that now also backs the catalog ingredient's inbound-ref chips.
- Eidoverse: `eidoverse.foundation` (read an inherited body), `eidoverse.adopt` (stand one up disarmed), `eidoverse.place-layout`, `eidoverse.draft-foundation` and `eidoverse.inspect-controller` mind tools; a Withdraw button on promoted local records; and a config editor that no longer requires re-installing a controller from scratch.
- A `factual` flag on the universe record, a seeded "Reality" universe, a Universe Builder toggle and a Real badge on the universe list.
- Catalog: a "Catalogue into" universe selector on ingest, a `?scrap=` filter, and an ingredient's source scrap rendered by title with a one-click "From the same source" list.
- Labeled auth sessions with `GET /api/auth/sessions` and a scoped `DELETE /api/auth/sessions/:id`, so an agent's loopback credential is visible in Settings > Security and revocable without kicking the human's tabs.
- Spawned agents receive a `PORTOS_API_TOKEN` loopback credential, so the `curl` commands their prompts hand them stop answering `401 AUTH_REQUIRED` on a password-gated install.
- Goal-fidelity follow-ups: file the finding on whichever tracker the project uses, and/or queue a CoS agent to reconcile it, with fingerprint-based duplicate suppression that fails closed.
- A calibration task is queued when a goal-fidelity finding turns out to be wrong, keyed on the blind spot rather than the run, so ten false positives from one gap fold into one fix.
- Bare `#1234` references in CoS agent summaries link to the run's own tracker, resolved server-side at spawn.

## Changed

- Stacker News items are screened at the shared untrusted-content boundary before either model call — the last ingress that had never crossed phase 1 — and the policy panel derives its source list from the server's rather than restating it.
- A provider reviewer that can never pass the tool-free gate is now badged "can't review" at selection time and refuses with a named configuration fault, instead of stalling the merge pipeline as a perpetual outage.
- An unavailable code review is no longer announced as a PR comment; it belongs in the run summary, and the PR stays open either way.
- The review loop's local-LLM reviewer runs through the auth-independent stdin bridge rather than the HTTP route, with an explicit 30-minute bound.
- Labels filed on a GitLab tracker use its scoped `::` separator, so `model`/`effort`/`planner` render as native scoped labels and `/do:next --model` can match them.
- `--reviewer-applies` is offered only for the codex pass, the one reviewer with a write-isolated profile.
- Peer-visit guidance names the shipped, install-portable world design separately from the host's own build, instead of telling a visiting Mind that everything it sees is private invention.
- The Mind playbook's maturity ladder counts what a mind built rather than install-constant scaffolding, so explore and construct are reachable on a real install and a brand-new one is no longer told to steward a mature Commons.
- Coordinate requires measured peer contributions, not mere reachability.
- The Eidoverse Foundations list still omits bodies; reads are addressable one at a time.
- `data/jev/` is machine-local, never federated, excluded from archival, and its corpora and cached embeddings are excluded from backup while trained heads are retained.

## Fixed

- The prompt runner's secondary backstop killed healthy streaming runs at ~302s and finalized them as a user cancel, so no provider was benched, no investigation was raised, and every produced token was discarded.
- An HTTP/2 GOAWAY is replayed even when the dead attempt itself spent the elapsed-time budget — the peer's drain schedule was making recovery less likely the longer it held the stream.
- A provider fetch failure now surfaces undici's cause chain instead of the generic "fetch failed".
- A federated peer's stale quota reading no longer ends the pending poll, stands in unlabeled, or renders a spent window as a live meter; staleness is judged against the window's own period.
- The video model list no longer reports an unprobed runtime as LoRA-incapable on the first page load after a server start, on both the internal surface and the A1111-compatible endpoint.
- A controller whose configured entity is gone no longer counts refused writes as delivered; repeated refusals disarm it and the panel says "Delivery refused".
- A controller store write can no longer downgrade a `schemaVersion` stamp written by a newer build.
- A universe `factual` conflict is now readable and resolvable in the Conflicts UI instead of landing there with the field missing from the diff.
- A failed Eidoverse world read no longer fabricates every district as changed by overwriting the place trail with `unknown`.
- Inherited Eidoverse foundations can no longer be republished as local work; re-use keeps provenance through a `derivedFrom` edge that a peer reads as the original author.
- Brain thread list ordering became engine-defined when two undated threads compared as `NaN`, which dropped or duplicated rows at the pagination boundary.
- Catalog ingests from the brain bridge resolved to Unassigned because the mount effect closed over the pre-fetch universe list.
- A resolver-supplied link destination goes through the same `javascript:`/`data:` guard a markdown link gets.
- A worktree branch whose PR merged minutes ago no longer reads as unmerged (the check asked this clone's stale local ref instead of `origin/<default>`), which was re-queuing tasks against work that had already shipped.
- A "resolve and merge PR #N" run is settled from forge state rather than from a diff that a merge leaves no trace in.
- An accessible label for the thread search combobox, and the apps page issue link is a button for mobile tap accuracy.

## Internal

- The three hand-rolled forge-issue filers collapse into one `fileForgeIssue()` exec wrapper with the home-path and credential scrub applied by construction — it was duplicated in two of the three and missing from the third.
- The untrusted-content source vocabulary, the jev abstention rule, the thread rules, the forge label separator, the `(kind, id)` ref table and the scope-adherence failure codes each became one definition both sides import, replacing mirrors that had already drifted.
- Server suite static-import budget work across several branches: the journal digest renders in the context service, the jev route schema imports from its declaring module, the federation guard's media-library edge is deferred, and the budget lands with restored headroom rather than a raised ceiling papering over an eager edge.
- Review-loop prompt snapshots are normalized so a Windows checkout does not fail CI on a path spelling.
- The shadow-observation counters move to a serialized store — two schedules folding into the same file were each discarding the other's increments.
- An ADR now records the authorization for the Eidoverse promote envelope to cross the federation layer, with a guard test that fails if style, ledger-only fields or unbounded prose ever reach a built offering.
- The bundled slashdo submodule moves to v3.39.0.
