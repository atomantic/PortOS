# Release v2.92.0 - Gatekeeper Loom

Released: 2026-10-10

## Highlights

- **Host-powered actions now need operator authority.** Remote desktop sessions, 3D rigging and retargeting, Deck and chiptune host actions, Catalog extraction/pruning/ingest, Creative Director and Commission workflows, Pipeline agent-backed generation, CoS approvals, and caller-prompted AI routes all refuse callers without operator authority.
- **Publish music videos to more places.** Facebook and LinkedIn join the destinations, with Fill-draft helpers, cross-links between a release's posts, recorded post links, Suno share-link support, a clearer "what will each post say" view, and DistroKid answers kept for every release.
- **Brain lists page correctly.** Lists keep paging past the first 25 records and across same-timestamp ties, failed reads no longer look like empty results, and graph similarity reads are scoped to bridged memories for a faster Brain graph.
- **Safer data and restores.** Snapshots stay alive while restore and download consumers read them, Apple Health imports can't overwrite a live restore, catalog payloads and universe tags are reconciled after a database restore, and Data Manager no longer offers one-click purge of drafts, accounts and Review Hub data.
- **Dependable updates and servers.** The server bind address and HTTPS loopback mirror port are honored under PM2, the target Node requirement is checked before apps are stopped for an update, fresh production installs are pointed to `npm start`, and release tags are pinned to the tree CI verified.
- **Polish across the UI.** Code Runner adopts the shared page header, FableLoom's empty state offers a create action, schedule and provider cards are less repetitive, and shared media actions have usable touch targets.

## Added

- Facebook and LinkedIn as music video publish destinations, cross-links between a release's posts, and recorded post links.
- Character-style choice when creating or starting a music video.
- Bounded agent session list with revoke-all on the Security settings page.
- Create-loom action in the FableLoom empty state; PageHeader shell on Code Runner.
- Artificial Analysis v4.3.2 scores for Claude Haiku 5.5 in model comparison.

## Changed

- Operator-authority checks on remote desktop, rigging/retarget, Deck/chiptune, Catalog, Creative Director, Commission, Pipeline, CoS approval and caller-prompted AI routes.
- Tool-free code reviews no longer invite repository inspection.
- Timeline preview plays the same source spans the export renders.

## Fixed

- Peer sync no longer drops same-date blood, epigenetic and eye records; concurrent Review Hub writes no longer drop items.
- Database start/stop/destroy report failures instead of success and bind to the native backend.
- Digital Twin metadata writes are serialized and soul documents written atomically.
- Calendar daily review pages past 200 events; calendar cache pruning requires complete Google event pages.
- Brain paging and failed-read handling; music-video search keeps results for structured concepts.
- LinkedIn Fill draft no longer stalls at the media editor; Persistent Mind turns survive a host suspend.
- On-demand model research no longer spawns two agents; mood-board cell counts and detail layout.
- Music video media-mode migration no longer depends on PostgreSQL.
- Chiptune publication stays inside the managed app through symlinked paths.
