# Release v2.117.0 - Rhythm Raccoon

Released: 2026-11-11

## Highlights

- **Music that stays in time:** full-song lyric alignment, vocal checks, and beat tracking keep captions and shots closer to the performance, including tempo changes and silent spans.
- **More ways to create:** Google and Higgsfield join the image, video, and music-video shot backends, while MiniMax H3-Image brings local image generation up to 4K on Apple Silicon.
- **Reliable local tools:** repaired, pinned installations restore TRELLIS.2 and Pixal3D workflows and make voice, vocal separation, and local video setup more reproducible.
- **Character comparisons:** render two characters on a shared reference sheet, keep a separate half for each, and refine the pair together.
- **The right song, once:** Suno imports verify the downloaded song, reuse existing takes, and preserve links back to the source.
- **Calendars on your day:** all-day events, daylight-saving transitions, weekly reviews, and goal progress now follow the intended local dates more accurately.

## Added

- Google image and video generation supports Gemini, Imagen, and Veo, with project and region settings, credential status checks, and music-video shot rendering.
- Higgsfield image and video generation supports family-specific references, durations, audio, cancellation, and music-video shots.
- MiniMax H3-Image offers local Apple Silicon rendering with reference images and resolution presets through 4K.
- Music Video can check a lyric sheet against the vocal, insert missing words, and check shot references against the shot sheet without overwriting newer selections.
- Character reference sheets can compare two characters with mirrored views and height rulers, attach the full sheet to both records, and retain each character's cropped half.
- Credential fields that accept JSON keys can open a downloaded key file directly into the private save draft.
- The Usage page explains how to retain Claude Code sessions so older usage history remains available.
- Runtime container images now receive scheduled software inventories and vulnerability scans with version and architecture evidence.

## Changed

- Python-based media and voice tools use private, hash-verified dependencies and build inputs; unsupported installation profiles explain their requirements before setup begins.
- TRELLIS.2 Install and Repair use verified private source snapshots on Metal and CUDA, and refuse incomplete repairs before generation.
- Pixal3D Metal builds and renders from the same pinned source snapshot while preserving Repair.
- Reference uploads to fal.ai share duplicate work, limit concurrency, retry transient failures, and honor cancellation and render deadlines.
- PortOS no longer asks for separate model license or territory acknowledgements; gated weight downloads continue to follow the distributor's access requirements.
- Credentials are alphabetized by service, and music-video production guidance uses the current Shots terminology.

## Fixed

- Full-song lyric alignment no longer overflows on long transcripts, accepts additional Latin letters, and preserves existing alignment when repairs fail.
- Lyric repairs keep line order, evaluate adjacent repairs together, serialize insertions, and retain check results when an insertion fails.
- Beat tracking follows tempo drift and retains beats through silent spans; saved analyses remain unchanged until Analyze runs again.
- Saving an animatic frame waits for active footage to decode, and layered video rendering waits for deferred modules to load.
- Music-video lists and project pickers refresh when another client creates, renames, or deletes a project.
- Invalid final-render references are refused before saving, and HTML development uploads accept the same extensions offered by the file picker.
- Suno exports use the current song's menu and verify its audio identity, refusing another song's download or an unverified file.
- Reimporting a Suno song selects its existing take and avoids duplicate tracks, including overlapping requests.
- All-day calendar events stay on the user's local day, daily bounds follow daylight-saving offsets, and missed weekly reviews catch up on the scheduled local day.
- Goal calendars return complete matches and progress trends reflect the correct history.
- Peer operations recover when response bodies stall, bound buffered responses, and retry unanswered library requests.
- Media-origin reconciliation avoids claiming another machine's copies and preserves uncertain origins until paired evidence resolves them.
- Cancelled page reads remain cancellations, and proxy failures explain that the server may be restarting.
- Local model and vocal-separation setup use compatible locked runtimes, verify completed installations, and expose accurate progress and repair status.
- Workflow linting catches invalid GitHub Actions configuration before merge, and workflow-token limitations receive a clear handoff.
- Backup guidance correctly states that deployed LoRA adapters are included.
