# Release v2.79.0 - Steady Songbird

Released: 2026-09-27

## Highlights

- **Safer database moves:** Settings can coordinate an offline database transfer, verify the restarted target, and resume an interrupted operation before allowing writes again.
- **Character voices:** Voice Studio creates reusable local voices with auditions, pitch and pace controls, and explicit character assignments.
- **Launch videos:** A dedicated app tab brings agent selection, music previews, downloads, dynamic motion graphics, and reviewed README GIF publication together.
- **History that stays useful:** Chief of Staff can compress terminal recordings while retaining summaries, prompts, feedback, and historical metadata.
- **Stronger host protection:** More actions that execute programs, manage databases, restore backups, or change execution policy require operator authority.

## Added

- Design and audition local AuK character voices on Apple Silicon, reuse saved voices for dialogue, and opt into buffered FableLoom replies.
- Download verified Qwen voice models for local design and cloning; supported CUDA hosts can fine-tune voices and audition verified checkpoints before promotion.
- Generate launch-video soundtracks explicitly, preview music and recent takes, and publish looping README GIFs through reviewed pull requests.
- Choose a dynamic motion-graphics treatment for launch videos and supply selected application context.
- Schedule research into local Apple Silicon image and video tooling when desired.
- Preview, filter, pin, compress, download, and cancel maintenance of archived terminal recordings; permanent recording deletion requires explicit consent.

## Changed

- Database migration keeps competing actions disabled until the target database is verified, and interrupted transfers retain their direction and recovery state.
- H3 live previews decode a smaller temporal window instead of the entire clip; end-to-end hardware speedup remains unbenchmarked.
- Creative commissions pass style-reference images to scene evaluation and local image rendering.
- Agent task creation remembers the last selected application.
- CLI code reviewers can run with the strongest isolation their provider supports.

## Fixed

- Reject incomplete legacy database dumps before replacing records, and preserve deployed LoRA weights in backups.
- Prevent overlapping draft sends, retain drafts during delivery, and require reconciliation of interrupted sends before retrying.
- Preserve message identity during browser archive and delete, and evaluate pending inbox messages before pagination.
- Preserve concurrent goal updates and calendar participant snapshots, recover calendar confirmations without duplicate progress, and use configured calendar providers for Agenda sync.
- Restore dictation to Shell and iTerm2 terminal views on Apple platforms.
- Improve fullscreen-log keyboard focus, table accessibility, heading structure, dark-theme contrast, and Usage-page touch targets.
- Restore automatic provider routing for untouched app agent actions while preserving explicit session overrides.
- Keep issue claims and worktree dependencies associated with their correct owners, and recover valid truncated agent completion signals.
- Show degraded Tailcat relay health and provide connection recovery controls without changing authentication or TLS behavior.
- Avoid double-counting imported Spotify listens and keep Signal system events out of contact history.
- Use native video canvas defaults while source images load and align H3 keyframe preparation with its reference implementation; scene-continuity validation remains ongoing.

## Validation notes

- Qwen fine-tuning requires supported CUDA hardware; real training and intelligibility validation remain separate hardware checks.
- AuK live replies use buffered playback rather than streaming.
