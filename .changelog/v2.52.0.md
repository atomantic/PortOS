# Release v2.52.0

Released: 2026-08-28

## Highlights

- Persistent Mind gains a unified dashboard, workspace preflight, image turns, configurable wake cadence, task-model restrictions, memory persistence, cleanup controls, and explicit visibility and capability controls.
- Chief of Staff gains a unified typed tool interface, an API explorer, a semantic tool resource, OpenAPI 3.0.3 output, and clearer task filing and completion policies.
- Quota Burn adds audit presets with standard model and effort pickers, while Rapid Reader adds resumable cursor progress and optional health and OpenClaw features become easier to operate.
- FableLoom adds conversational episode feedback, and OpenWorld improves gameplay feedback and rendering performance.
- Release engineering now runs related tests once across available CI runners and keeps generated API and socket catalogs aligned with their source contracts.

## Added

- Added Persistent Mind workspace preflight, image attachments and image turns, task filing parity, self-authored memory persistence, tools access controls, wake-cadence settings, task-model allowlists, and cleanup controls.
- Added the unified CoS tool interface, API explorer, minimized semantic tool resource, agent tool contracts, and OpenAPI 3.0.3 documentation output.
- Added conversational FableLoom episode feedback and its stage configuration.
- Added Quota Burn audit presets, standard model and effort selectors, collapsible configured jobs, and preset filtering.
- Added Rapid Reader cursor resume, OpenWorld health tracking, and an OpenClaw instance feature flag.
- Added the Chief of Staff configuration redesign and shared AI selectors for feature agents.

## Changed

- Persistent Mind now coordinates workspace access, visibility, provider readiness, authority, task grants, task completion landing, dashboard actions, and submitted-task state through explicit persisted controls.
- CoS navigation, API route catalogs, socket event catalogs, MCP tool contracts, and generated OpenAPI descriptions now share the same documented inventory.
- CI test planning now avoids rediscovering related tests and executes each related test once across runner CPUs; expensive integration scenarios are consolidated.
- Brain, goals, catalog, quota, feature-agent, notification, theme, and feed interactions now expose clearer state, touch targets, confirmations, focus behavior, and responsive layouts.
- Usage, autobiography, journal, brain, Obsidian, LoRA, schedule, and perpetual-work persistence paths now batch or serialize high-frequency mutations where required by their storage contracts.

## Fixed

- Fixed Persistent Mind lifecycle, wake, MTPLX, attachment cleanup, image recovery, idempotency, retry, provider-readiness, capability-save, workspace-preflight, and update-race edge cases.
- Fixed task and agent recovery so duplicate restarts, stale plans, incomplete claims, invalid completion overrides, and missing TUI binaries fail safely and report actionable state.
- Fixed goal creation, progress, milestone, edit, and decomposition submissions; catalog media and relation detachment, revision restore, draft reset, and ingredient editing confirmations now preserve user intent.
- Fixed mobile and accessibility regressions across feature agents, quota actions, BrainGraph filters, feed actions, Inbox review controls, theme menus, command palette focus, and notification controls.
- Fixed peer header handling, Basic-auth cache entries, peer-sync authorization coverage, update-process identity checks, Whisper port mapping, and OpenClaw runtime-state distinctions.
- Fixed quota audit scheduling, refusal explanations, migration reversibility, provider readiness binding, task-catalog repair, and related archive and cache performance paths.
