# Release v2.64.1

Released: 2026-09-12

## Highlights

- **More accurate story repairs:** Arc verification now keeps episode role and length corrections instead of silently applying only synopsis changes.
- **Repairs target the real foundation gaps:** Foundation maintenance now chooses dimensions below the requested score, improving the areas that are actually holding a series back.
- **Safer character repairs:** Named character findings no longer rewrite unrelated ensemble history, and oversized repair batches are split or refused before they can damage authored records.

## Fixed

- Episode repair now persists sparse dramatic-role and length corrections, clears expanded beats when the plan changes, preserves synopsis text for metadata-only repairs, and rolls back only fields written by the repair.
- Foundation repair now prioritizes dimensions below the requested score while retaining the existing weakest-dimension diagnostic.
- Character foundation repair preserves existing character history, profiles, and visual identities, scopes changes to the named characters and aliases, and refuses a single target that cannot fit before calling a provider or writing canon.
