# Release v2.119.0 - Frame Fox

Released: 2026-11-13

## Highlights

- **Standalone films:** Create Blender film projects, send them to Music Video, and combine Blender shots with code animations and layers.
- **More expressive cuts:** Add pictures before the song starts, dissolve between film shots, fade to black, and review motion with contact sheets.
- **Clearer shot progress:** Mark shots Done in the editor or Scene board, and confirm an approved still still matches its shot without repainting it.
- **Smoother playback and rendering:** Rewind glitches render without stalling, and reversed clips keep their picture while a glitch is playing.
- **Easier release preparation:** Capture clean, full-resolution publishing frames and skip individual publishing platforms for one release.

## Added

- Standalone Blender films support their own soundtrack, timeline, acceptance review, and Music Video handoff.
- Film shots can use browser-rendered code animation or overlay code layers, including films that do not need Blender installed.
- Blender film lead-ins play before the song in previews, cuts, and final renders.
- Film cuts support dissolves, beat toggles, and fades, with clear guidance when a transition needs more rendered frames.
- Contact sheets make it easier to inspect motion across a Blender film shot.
- A reusable cel animation template includes depth, rigging, walk motion, beat timing, and neutral example scenes.
- Shot completion controls appear in the editor and Scene board, with completed cards clearly marked.
- Publishing platforms can be skipped for an individual music video release and restored with Undo.

## Changed

- Publishing kits capture clean frames at full resolution and reuse approved artwork frames where available.
- Suno Hooks have their own captions and use the intended song window for vertical videos.
- Cover lettering starts from the artist's saved style, and store genre suggestions also use a library song's Suno style.
- Mood board prompts start collapsed, listings are alphabetized, and style choices are easier to browse.
- Model comparisons include refreshed Gemini pricing, intelligence scores, and benchmark cost evidence.
- Local creative runtimes receive coordinated dependency and compatibility updates across music, video, image, and 3D tools.

## Fixed

- Rewind effects with many smeared bands no longer cause renders to stall, and glitches over reversed clips no longer flash the shot's last picture.
- Replacing a shot's own selected still preserves its frame prompt; directors can reconfirm an older approved still against the current shot.
- Blender shots resume after a server restart, preserve compatible older renders, and can end on the frame containing the song's end.
- Film rendering preserves shot looks, code-layer transparency, transition frames, soundtrack alignment, and lead-in frame rate.
- Shot editor saves avoid phantom unsaved changes after failure, and the sticky header stays aligned while scrolling.
- Suno Hook preparation finds renamed songs, retries temporary search limits, waits for uploads, and aligns audio using the editor's precise hover time when available.
- Audio-reactive scene clips retain the exact source-song window used for generation, and downbeat alignment follows confident song structure.
- Codex image generation checks reference readability, records reference filenames, and retries one false missing-reference response.
- Video generation accepts JSON requests using existing gallery images.
- Catalog-first Cast & Sets check-in can save a director look, and mood board sync honors peer-hosted media while preserving style and finish.
- Reviewer settings preserve supported legacy model and effort choices.
- Telegram forwarding recovers from a temporary startup outage with bounded retry delays.
