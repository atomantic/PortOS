# Release v2.83.0 - Stagecraft Songbird

Released: 2026-10-01

## Highlights

- **Music videos from plan to production:** choose code, stills and generated footage shot by shot, preview the video allowance, and produce only the missing assets after reviewing a budgeted pilot.
- **Sharper musical storytelling:** cut existing footage to the song's energy and sung words, build hook lyrics word by word, and bind narrative graphics to timed song events.
- **Repairs preserve good work:** preview timing changes and stale dependencies, check performance evidence, and repair affected shots or failed performance endings while retaining accepted footage.
- **Ready to share:** make vertical and square cuts, release encodes, captions, chapters, thumbnails and editable platform copy; review browser-filled posts before submitting them to enabled platforms.
- **Code Animation projects travel:** save Production projects and source revisions, then download portable packages with revision checks for another rendering environment.
- **More image and provider choices:** generate images through fal.ai and choose ChatGPT subscription or API-key authentication for each Codex provider.

## Added

- Music Video medium plans with explicit generated-video allowances, treatment-driven mixed-media composition documents, asset preflight and selective code-first production.
- Budgeted production pilots, authored-shot plate checks, shot-action inspection, lip-sync evidence windows and selective dependency repair.
- Piecewise audio-timing previews, synchronized performance review and opt-in color curves with song-timed grain.
- Mood-board image conditioning, song-driven intercut editing, hook word builds and keyword or number graphic cards.
- Named narrative events tied to musical onsets, aligned words or song times, with an event lane and section-level revision previews.
- Vertical and square social cuts with suggested hooks and optional audio fades.
- Publishing kits with release encodes, teasers, thumbnails, timed captions, chapters and editable platform copy.
- Opt-in publishing destinations, platform accounts and post feedback; browser-assisted draft review and submission, including native Reddit video uploads.
- Saved Code Animation Production projects, source revisions and portable package download and validation.
- fal.ai image generation with model selection and cost tracking.
- Per-provider Codex authentication choices.

## Fixed

- Publishing previews, making-of notes and links reset when switching Music Video projects; late responses cannot restore another project's drafts.
- Publishing-kit builds reject duplicate in-flight requests and retain the identity of their actual source render.
- The Publish stage retains icon-based navigation on mobile.
- Composition previews report missing media while continuing to load available assets.
- Native Reddit video posts honor an explicitly requested first comment, matching text and link posts.

- Music Video production requires a current approved plan, stops unchanged terminal retries, preserves conservative budget charges after interruptions and respects cancellation at submission.
- Performance evidence stays separate from video duration checks; unsupported or unknown mouth-timing evidence stops automatic paid retries.
- Changing a singer, timing or conditioning input invalidates the affected evidence while preserving unrelated shots and historical assets.
- Code Animation explains when an export has no audio, and Production import failures are announced to screen readers.
- Image LoRA tests choose a compatible local runtime; image dimensions and backup retention follow supported server limits.
- Mood-board controls remain responsive to available width.
- Agent completion details remain behind Show, with working report links and retry after failed detail loading.
- Codex model-access rejection stops unproductive launch retries, and local model comparisons display zero API cost with sourced quality scores.
- App log requests reject invalid process names, bound requested output and return an error when logs cannot be read.
- Pregate rejects unresolved conflicts and unsupported Node versions before running checks.

## Internal

- Shared duration estimates, usage scanners, sprite reference planning and song-part choices were simplified without changing their public contracts.
- Database cutover and browser-render acceptance checks retain clearer failure evidence and more reliable cleanup.
- Updated urllib3 to 2.8.0.
