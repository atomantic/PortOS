# Release v2.74.0 - Performant Dragon

Released: 2026-09-22

## Highlights

- Brain and memory collections are easier to browse at scale, with stable pagination, richer previews, and image-aware reading.
- Chief of Staff workspaces load only the active collection, replace repeated polling with live invalidation, and page completed history efficiently.
- Models and code-review settings are organized by destination, with clearer follow-up workflows and a refreshed local-LLM catalog.
- Sharing controls are more accessible with explicit popover state, keyboard dismissal, and focus returning to the trigger.
- Background health and synchronization failures are surfaced more truthfully, making stalled work and federation problems easier to resolve.
- Full-suite CI is more reliable through corrected import budgets, timeout handling, current-head merge gates, and expanded source guards.

## Added

- Stable cursor pagination for the Brain inbox and memory collections.
- A redesigned Brain memory reader with full-content previews and image previews.
- Separate Code Review setup and Follow-up destinations in the Models workspace.
- Local-LLM catalog entries for Llama 4 Scout, DeepSeek-R1 70B, and Qwen2.5-Coder 14B.
- Coalesced system-activity invalidation and a bounded completion-order index for agent history.

## Changed

- Chief of Staff pages now load the selected collection on demand and use reconnect-aware invalidations instead of page-wide polling.
- Schedule timelines, health alerts, and learning controls now expose clearer state and recovery actions.
- Models pages use destination-specific titles and avoid repeating headings already supplied by the surrounding shell.
- Share and sync popovers now expose their open state to assistive technology and close predictably with Escape.
- The release and CI guards now account for current-head checks, source-file extensions, and the dependency-supported Node range.

## Fixed

- Superseded worktrees no longer hold an idle claim slot, and local inference no longer occupies the global agent slot for an entire turn.
- Federation sync failures remain visible and no longer advance the last-success timestamp when a cycle fails.
- Full-suite tests no longer fail on cold imports, detached-process timing, or asynchronous UI state that had not settled.
- Removed unused inbox client code, duplicate page headings, collection-level attribution clutter, and unsafe log-level guard gaps.
- Deleted Brain records collapse from the visible list without requiring a full reload.
