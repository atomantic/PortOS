# Release v2.68.0

Released: 2026-09-16

## Highlights

- **PortOS can now update itself unattended,** but only in a window where nothing is running: the updater refuses on a dirty checkout, a wrong branch, an unpushed commit, or any in-flight agent, render, or Mind turn, and queues a repair task instead of stashing your work.
- **A new Subscriptions page under Models** answers "which plans do I pay for, are they on, what tier, and what are they costing me?" in one row per plan — enable/disable, tier, price, spend, and quota meters that previously lived on three separate screens.
- **Local model servers get their own Runtimes tab,** split out of the LLMs catalog so managing llama.cpp / MTPLX / Slotstream / Ollama / LM Studio lifecycles is no longer buried behind a pill with no URL of its own.
- **A long think now reads differently from a stall on the Mind page:** live elapsed time, heartbeat freshness, a distinct "stalled, checking…" state, model-loading residency, and a quota pause that names the provider's limit with its real retry time.
- **A local daemon's served context window is read live and respected,** so an oversized prompt is refused in milliseconds instead of stalling for the provider's full ten-minute timeout — and the chunker and provider card budget against the same number the server enforces.
- **A sick provider is benched even for pinned callers,** so a backend that fails every call stops burning its whole timeout on every wake and stops reading green on the Providers page.
- **Thousands are grouped in every user-facing count and dollar amount** (`2,762`, `$4,610.09`), pinned to en-US and enforced tree-wide so a bare `.toLocaleString()` can't come back.
- **A relaunch onto a different provider is no longer recorded as a failed run** — no red card, no failed task in the daily report, no phantom entry in the needs-feedback banner.
- **CI got substantially cheaper and less flaky:** an externally cancelled run is told apart from a red one and retried once after the queue drains, the verdict is published on the PR itself, a full plan stops running the whole Windows suite when nothing Windows-sensitive changed, and three real causes of client shard-1 flake are fixed.
- **The persistent mind picks a maturity-aware phase each wake** (explore / construct / maintain / coordinate) from live Eidoverse signals, and its world edits are now explicit proposals whose commit is decided by the world's own acknowledgement.

## Added

- Unattended automatic updates (Update tab → Automatic updates), with one shared definition of "idle" (`server/lib/systemIdle.js`) consumed by both the dashboard activity widget and the updater.
- `/models/subscriptions` — a per-plan page joining family enable/disable, plan tier, price, spend, and quota meters.
- `/models/llms-runtimes` — local model servers as a top-level Models tab, with the old pill URL redirecting.
- Live turn progress on the Mind page: elapsed think time, heartbeat freshness, stalled detection ahead of the watchdog, quota/degraded pause with its next retry, and local model residency.
- Free-tier usage on the Usage page, estimated from the ledger in blocks.
- `formatCount` for exact grouped integers, with `—` for a count that was never measured.
- A maturity-aware phase picker for the persistent mind's continuous play, surfaced in the Mind Context preview and each phase's working note.
- An agent-free resilience assay harness for Eidoverse world foundations (`npm run eidoverse:assay`), replaying a contribution through reconnect / restart / missing-dependency disturbances.
- Ten sourced SWE-bench rows and a `benchmarkModel` catalog field, so the local coding agents PortOS recommends can finally appear on Models → Comparison.
- A CI cancel-recovery workflow that re-dispatches an externally cancelled run once, after a five-minute wait, and publishes its verdict as a neutral check run on the PR.
- A responsive two-column grid for the Settings → Credentials cards, and a link from the NVIDIA NIM provider card to build.nvidia.com for API keys.

## Changed

- Prompt budgeting, the provider card's meter, and the pre-dispatch gate all fold in a local daemon's observed context window, so they can no longer disagree about what the server will accept.
- A pinned call now records provider health; a timeout benches the provider for at least the budget it burned rather than a flat 60 seconds.
- A manual maintenance run can dispatch on a provider outside the four subscription families, attributed to its own run id instead of a subscription it never touched.
- The quality-runner and maintenance-run provider pickers offer every capable process provider, not just familied ones.
- Eidoverse `augment`/`say` return explicit accepted / rewritten / refused outcomes with a `committed` flag, so one bad operation no longer erases the record of operations that already landed.
- Breadcrumbs across the Models surfaces are derived from the route through the nav manifest instead of being typed out, with a tree-wide guard against a new hardcoded one.
- The Subscriptions page reuses the Usage page's own quota ladder, money cells, meter, and report windows, and a period click no longer respawns a multi-second CLI quota scrape.
- OpenCode sessions are pinned to the `build` agent vendor-wide, so an interactive run can write its own completion sentinel.
- A full CI plan escalates the Windows suite only when a matching trigger is Windows-relevant, cutting a full run from 12 jobs / 28.7 runner-minutes to 10 / 18.4.
- Lint moved off the largest client shard into its own job, and client `node_modules` is cached for the jobs that install it.
- Every import-safe CLI routes through a shared direct-invocation helper, so a symlinked checkout still runs it.

## Fixed

### Providers and local models

- Gateway-backed OpenCode wrappers (NVIDIA NIM, OrcaRouter, OpenRouter) carry the sibling's API key through provider clones and fallback picks, instead of dispatching with no Authorization header.
- An undeclared local model id no longer resolves to a different model's benchmark name through the hosted normalization rules.
- The fleet host's manage button lands on the page that actually holds the server control, not the weights catalog.
- A caller that creates its own run record has it finalized when the context gate refuses, instead of leaving a run that never ends.
- The context-window refusal acts on the provable floor — the prompt alone — unless the caller declared its own output reserve.

### Unattended updates and idle detection

- Two reads in the idle gate failed open: an unreadable image-to-3D build list or an unreadable pending-task list reported the same thing as an install with nothing running — the value that unlocks an unattended restart. Both now block the verdict instead.

### Persistent mind phase selection

- A single always-reachable peer no longer pins every wake to the `coordinate` phase; the peer signal now measures reachability, says so, and ranks below construction, so a Commons short of maturity keeps building.
- The phase reason no longer prints a coarse install-health enum as "50% recent failure rate" — only a measured rate is reported as a percentage.

### Chief of Staff and agents

- The `.agent-done` sentinel is removed on every completion path, not just the in-process TUI one, so worktree-less runs stop littering managed app repos.
- A sentinel is kept when finalize threw before recording an outcome, since for a programmatic-I/O task the sentinel *is* the deliverable.
- The unscoped `.agent-done` is never retired on an id-resolution failure.
- A feature agent's hand-back is gated on a continuation actually being queued, so a stranded retirement can no longer park a dead task id and disable the agent permanently.
- A missing-sentinel warning names the merge-gate nudge that deleted it, rather than pointing at a lost write.
- The GSD tab is hidden when its feature is off, matching the sidebar.

### Persistent mind

- A quota autopause reads its retry time from the readiness probe — the only thing that sets it — and each blocked state reads its own retry axis.
- A paused or clock-jumped probe no longer advertises a retry that is not coming; an unconfigured provider is told it needs the user, not patience.
- The chat turn indicator's accessible name is the turn stage, so a screen reader stops re-reading elapsed time every ten seconds.
- An idle day no longer reads as a 100% failure rate and forces every wake into the maintain phase, and a failed district read reports unknown density rather than an empty Commons.

### Formatting and UI

- `formatUsd` groups thousands and snaps a rounded-away saving onto a true zero, so it can't render as a loss.
- The 82 remaining bare `.toLocaleString()` renders under `components/`, `pages/`, and `lib/` converge on `formatCount` / `formatDateTime`, with a guard test banning new ones.
- `TabPills` advertises `aria-controls` only for the panel that actually mounts, with a guard asserting every rendered aria reference resolves.
- A quota window whose usage could not be read renders "—" rather than a confident "0% used", so a plan that may be fully spent no longer reads as untouched.
- Comic page lightbox items are built through `normalizeImage`, so pinning a page to a mood board dedupes against the same image from Media History and keeps its render lineage.
- GitLab issue label colors show in the managed-app Issues tab.

### CI and release infrastructure

- An externally cancelled CI run is reported as cancelled, not as a red test suite, and its verdict reaches the PR as a neutral check run.
- The cancel retry waits five minutes and re-checks every guard afterward, so a supersession or human re-run that lands during the wait still wins.
- Three fail-open paths in the cancel-recovery guards are closed, including a job whose step failed while its conclusion read `cancelled`.
- Client shard 1 stops going red on a different timing-sensitive test each run: a vacuous load barrier, an async budget under what a 2-vCPU runner needs, and two ordering races.
- The sparse-checkout cone guard normalizes to POSIX paths, so it holds on the Windows shard.
- The CI gate fails closed when no job results were supplied at all.

### Security

- Wan 2.2 checkpoint indexes are screened with the same validator the MiniMax H3 runner uses, now lifted into one shared module — upstream has rejected a fix for GHSA-4j2p-28q2-5m79, so the mitigation lives here permanently.
