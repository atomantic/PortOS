# Release v2.111.0 - Texture Toucan

Released: 2026-11-05

## Highlights

- Photoreal environments gain downloadable CC0 material textures, improved floors and lighting, and a way to open their saved scene in Blender before rendering.
- Music videos get printable QR flyers with full-page and two-per-page layouts, gallery artwork, and Clean or 80s styling.
- The music-video Publish page remembers platform answers and explains queued browser fills so work is easier to resume.
- Cameo reference photos can be reviewed together, and linked object images are visible on the music-video Look step.
- Local LTX 2.5 video generation supports experimental reference-image conditioning alongside an opening frame.
- Mobile navigation and controls are easier to tap, with notifications and required actions visible in the top bar.

## Added

- Pick Poly Haven CC0 textures for Photoreal materials; downloaded maps travel with the saved Blender scene.
- Build and open a Photoreal scene in Blender without first rendering a camera, with setup and recovery guidance in the same view.
- Print music-video flyers with a scannable QR code, optional typed link, saved text, gallery artwork, and full-page or half-sheet layouts.
- Browse cameo reference photos in a grouped grid, follow their sources, and remove unwanted photos without reopening each cameo.
- Use linked object images as explicit music-video look references.
- Apply the optional LTX 2.5 Ingredients adapter to local reference-conditioned video; adapter access requires accepting its provider terms, and identity preservation remains experimental.
- Clear failed and canceled image, video, and upscale jobs together while retaining active jobs, completed jobs, and recovery records.

## Changed

- Catalog ownership controls move into a compact header dialog that retains ownership, usage, canon, and redesign actions.
- Storyboard and composition preview film looks start off and share a viewer preference without changing the saved render look.
- Music-video platform rows remember draft answers, fold when done, support gallery story images, and show which browser operation a queued fill is waiting for.
- Image-reference controls explain attachments omitted by model limits and distinguish requested CLI attachments from verified provider inputs.
- Music-video cleanup distinguishes missing final videos from empty files and labels storage measured on the PortOS server.
- Frame and mood-board prompts resize to their content as layouts and fonts change.

## Fixed

- Preserve saved Photoreal looks through canon synchronization and profile saves, including synchronization between different install versions.
- Include saved photo textures when opening a newly built Blender scene, and wait for pending Look changes before rendering cameras or fly-throughs.
- Improve Photoreal wood floors, greybox edges, and spot-light transitions.
- Allow contained Blender to start on Apple silicon with the required device access, use CPU rendering in that mode, and explain unsupported engines and render crashes.
- Accept Blender 5 compressed scene files and allow ordinary macOS EEVEE renders to finish before inspecting the GPU backend.
- Generate standards-compliant QR codes for flyers and FableLoom session joins, and keep flyer artwork synchronized to peers.
- Honor shot film looks in document videos and previews.
- Preserve overlapping Writers Room edits and serialize Brain metadata updates.
- Append a Writers Room sprint only once when promotion requests overlap.
- Keep Code Animation project pagination stable and reject invalid pagination timestamps.
- Recheck removed broker listings so reappearing listings can be found again.
- Show retry actions when Telegram settings, remote branches, or music-library reads fail.
- Keep the music-library picker usable after switching tracks during a pending read, and discard stale results when returning to a track.
- Prevent mobile dashboard and instance-sync overflow, enlarge small navigation and icon controls, and display zero-minute task estimates correctly.
- Avoid duplicate Digital Twin evaluation runs and late state updates after evaluation or agent views close.
- Respect externally managed Claude session PRs instead of launching a second coordinator on their branches.
- Identify rejected agent credentials separately from missing credentials without automatically changing credentials.

## Internal

- Reduce release test-planning work and defer optional heavy workflows until they are needed.
- Run full local unit validation in the same sequential shards used by hosted CI, with improved failure replay diagnostics.
- Retry transient Debian Snapshot package-download failures during the SuperCollider build and correct the Git capability probe used by the doctor command.
