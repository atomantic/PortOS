# Release v2.53.0

Released: 2026-08-29

## Highlights

- FableLoom gains a full series-planning workspace: AI-drafted series plans, an episode outline view, interactive playback modes, camera-cut nodes, shot continuity and reference handling, audience participation modeling, and story federation.
- IdeaLoom adds a two-way Obsidian exchange with an explicit list-editing panel and a local list API, plus hardened conflict handling so edits, deletions, and Markdown round trips stay in sync without clobbering or resurrecting notes.
- FaceTime Audio gets a full control plane — outbound and inbound calls, live meeting-audio capture through the call-host bridge, and call audio routed through BlackHole into the voice pipeline — and the Persistent Mind can now place a call when nothing on screen can reach the user.
- Rapid Reader adds a durable shelf so saved books survive a refresh, a live H:MM:SS countdown, and improved navigation and text flow.
- Signal settings moved into Comms, agent activity streaks were retired, and a new read-only `npm run doctor` command reports install prerequisites.

## Added

- Added the FableLoom series-planning workspace, AI-drafted series plans, episode outline view, interactive playback modes, camera-cut nodes, and audience participation modeling.
- Added FableLoom story federation and scene video generation.
- Added a dedicated Brain Ideas page, IdeaLoom list editing panel, and local IdeaLoom list API.
- Added an explicit IdeaLoom Obsidian exchange.
- Added the FaceTime Audio control plane, inbound-call answering, live meeting-audio capture through the call-host bridge, and BlackHole audio routing into the voice pipeline.
- Added Persistent Mind calling as a fallback channel when nothing on screen can reach the user.
- Added a durable Rapid Reader shelf, live countdown timer, and navigation/text-flow improvements.
- Added a read-only `npm run doctor` install-prerequisite report.
- Added drifting cloud banks to OpenWorld.

## Changed

- Moved Signal settings into Comms and retired agent activity streaks.
- FableLoom playback, shot continuity, transitions, and plan replacement are now hardened against regeneration and review-surfaced edge cases.

## Fixed

- Fixed IdeaLoom sync so deletions actually delete, edits don't clobber or resurrect notes from Obsidian, Markdown round trips are preserved, and the federation boundary stays correctly scoped.
- Fixed Spotify and YouTube redirect URIs to derive from the request origin and Tailscale host, preserving query params on legacy redirects.
- Fixed pitch-analysis mic capture to disable browser audio processing and report processing state consistently.
- Fixed calendar sync to never prune events from a partial CLI sync payload, and POST daily practice to rotate across eligible drills instead of repeating one.
- Fixed generated API route, socket event, and OpenAPI catalogs to stay aligned with their source contracts.
- Fixed buffered spawn timeout cleanup, NVIDIA Kimi provider configuration, and federated peer label and media-status handling.
