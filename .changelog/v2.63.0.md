# Release v2.63.0

Released: 2026-09-12

## Highlights

- **Safer saved data:** unreadable settings and records now stop writes that could replace existing data, and incomplete legacy imports remain retryable after repair.
- **Faster browsing:** image galleries, universe and series lists, apps, and pipeline issues load smaller summaries and fetch detail when needed.
- **More control over automation:** scheduled claims can leave PRs open for review, schedule cards show global pause, and quality checks can run manually with schedules disabled.
- **Keyboard and mobile improvements:** navigation, notifications, tabs, Jira ticket dragging, SongBook, and generation controls are easier to use across screen sizes and input methods.
- **Voice setup:** Piper replaces the retired Kokoro engine, with migration guidance that preserves existing settings and character recordings.
- **Shared quality evidence:** matching managed apps can combine numeric assessments across enabled peers and use a dated release snapshot.

## Added

- Scheduled issue claims can leave their pull requests open for review instead of merging automatically.
- Empty briefings offer a generation action and show queued or active progress through completion.
- App quality categories expose audit controls beside their evidence, preserve selected overrides, and support parallel manual checks.
- SongBook wraps chords with lyrics while keeping chord diagrams visible.
- Jira Kanban supports keyboard ticket dragging, screen-reader announcements, and focus restoration after success or rollback.

## Changed

- Image Gen initially loads recent renders, pages hidden images, and preserves browsing during background refreshes; LoRA dataset imports gain gallery paging and search.
- Universe, series, app, and pipeline issue lists use compact summaries while editors and exports retain full detail.
- Persistent Minds load conversation context only after a turn is admitted.
- Writers Room synchronizes authored cast, places, and objects with their works while preserving newer local edits and compatibility with older peers.
- The API Explorer REST reference uses a native operation list, reducing client dependencies.
- Voice settings guide existing Kokoro installs to Piper without downloading models during migration; historical character voices remain preserved until explicitly replaced.
- General settings prioritize controls that require saving, and calendar empty states offer relevant next actions.

## Fixed

- Unreadable integration settings, personal records, creative catalogs, media state, sharing records, and pipeline stores no longer silently turn into writable empty defaults.
- Legacy imports identify incomplete sources and can complete after those sources are repaired.
- Time Capsule rebuilds corrupt indexes from saved snapshots, tolerates missing optional source files, and preserves listings when snapshot deletion fails.
- Sprite walk-set unlock preserves finalized files when selection metadata is unreadable.
- Blank agent-personality forms can generate a name, and failed resolve-and-merge actions offer the correct retry.
- Collection deletion refreshes Unsorted counts and covers, and API Explorer ignores stale responses after changing surfaces.
- Video generation keeps its display-sleep warning visible beside Generate when mobile Options is collapsed.
- Updated js-yaml overrides to 4.3.2 to address a high-severity advisory.
- Historical weekly digests use the requested week's dates and handle older digests without summaries.
- Route changes no longer let stale app, agent, Brain Notes, 3D, or GSD document requests replace the latest selection.
- Review Hub preserves global triage counts across filters and keeps status tabs synchronized with live updates.
- Navigation and notification panels preserve keyboard focus, respect Escape handling, and restore focus when dismissed; shared tabs and loading indicators improve keyboard and reduced-motion support.
- Mobile layouts keep universe names, repository paths, messaging controls, and generation actions readable and reachable.
- Backups retain progress during lengthy work and detect stalled subprocesses; forge operations preserve successful results during shutdown.
- Voice subprocess failures no longer crash the server through broken input pipes, and invalid Wan frame counts are rejected before rendering.
- Prompt Guard processes complete overlapping input windows and reports actionable setup failures without exposing private input.
- Agent completion, handoff, and worktree cleanup use consistent outcomes; review preflight failures remain visible for recovery.
- Local model upgrades verify the resulting version, and unavailable quality checks are excluded from suggested actions.
