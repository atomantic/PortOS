# Release v2.73.0

Released: 2026-09-21

## Highlights

- **Development maintainer:** Persistent Mind can optionally coordinate explicitly selected repositories with an agent-free watchdog, bounded local inference, and private process audits.
- **Catalog extraction:** Review source-grounded ingredients and relationships before saving them, with context-aware chunking and clear partial-result feedback.
- **Focused workspaces:** Models, Jev, Performance, Runtimes, CoS Tasks, Settings, Brain, and Apps put frequent work and selected evidence closer together.
- **Action queue:** The notification bell, dashboard, and Actions page share required actions, with durable reminder deduplication and mobile-friendly cards.
- **Local media:** Add Qwen-Image 2.1 generation and editing, plus clearer local media installation and repair controls.
- **Decision classifiers:** Explore Jev and optional Laya-MLX experiments in a dedicated workspace without changing existing automation choices.
- **Reviewer controls:** Configure accessible fallback groups, preserve model and effort choices, and surface unavailable reviewers and incomplete assessments.
- **Grok 4.7:** Refresh provider defaults, verified capabilities, and context-tier pricing while preserving configured selections and historical benchmark evidence.
- **Safer operations:** Self-updates preserve local changes, repair stale submodules, and make host-access risks and contribution boundaries explicit.

## Added

- An opt-in, machine-local development maintainer role with explicit repository scope, cadence, permission checks, and readiness feedback.
- A deterministic development watchdog that checks current issues, pull requests, claims, and participating peers before handing eligible work to existing scheduled workflows.
- Durable local inference allowances and explicitly authorized escalation choices for maintainer reasoning, plus bounded private process audits that publish only synthetic, source-anchored findings.
- Catalog extraction drafts with quoted relationship evidence, selective ingredient and relationship review, and atomic saving of accepted relationships.
- Context-aware extraction that uses one call when the source fits, splits longer sources without silently dropping content, and distinguishes partial results from successful empty drafts.
- A Decision Classifiers workspace with shareable Jev task views and manual Laya-MLX experiments on supported Apple Silicon systems.
- Local Qwen-Image 2.1 generation and editing, including reference-image uploads and transparency-preserving output.
- Media model availability controls and agent-assisted requests to add catalog support for a model.
- Configurable autobiography prompts, image-analysis indicators in mind model choices, and visible agent invocation effort.
- An app Git action to open a shell terminal, command search from the mobile header and navigation footer, and completed-agent cards that can receive follow-up inbox feedback.

## Changed

- Models navigation groups model libraries, runtime operations, decision classifiers, and performance tools while retaining existing deep links.
- Jev presents focused experiment, integration, results, training, and setup views; Model Performance opens on results with selected evidence alongside them.
- Runtimes uses a selectable operations roster, and CoS Tasks keeps queues visible while capture and configuration use compact, draft-preserving controls.
- Settings General and Backup emphasize common tasks; Brain preserves selected records through refreshes; Apps presents its collection first and distinguishes loading, empty, and unavailable states.
- Required actions share consistent previews across the bell, dashboard, and Actions page; reminder delivery survives reloads and avoids repeats across browser and Telegram surfaces.
- Action cards adapt to narrow screens and can queue app investigations, while health alerts retain actionable resolutions and correction baselines.
- Reviewer settings support accessible fallback tiers and bulk forge reviewer entry; GitHub and GitLab reviewer users follow the target forge's review lifecycle.
- Quality snapshots publish numeric measurements through a pull request that merges after passing checks.
- CoS task templates have a per-install feature toggle, and the retired NVIDIA Kimi preset is removed only when it remains an untouched, unused shipped default.
- Updated bundled development workflows, interface libraries, Google API clients, PDF support, and test tooling.
- Fresh Grok CLI/TUI and API presets default to Grok 4.7; additive migrations offer it to existing installs and add sourced standard and long-context pricing records.

## Fixed

- Self-updates no longer stash local work implicitly; managed repository updates can reconcile divergence and repair stale submodules before escalating a sync failure.
- Streaming AI requests honor their configured stall and runtime bounds instead of ending at an unrelated transport timeout.
- Deterministic maintainer policy denials wait or pause without repeated inference retries; continuation tool descriptions remain within bounded context budgets.
- Maintainer issue claims use configured scheduled batches, preserving provider choices, effort, filters, and reviewer settings.
- Catalog ingestion preserves distinct uncertain identities, honors the Brain model handoff, and retains image-generation metadata with catalog images.
- FastH3 V2 advertises only the text-to-video mode supported by the pinned runtime, and missing MiniMax MLX assets are provisioned before rendering.
- Image runtime controls can detect and repair missing Qwen pipelines; installers continue running when switching provider tabs.
- Optional LTX pipeline arguments remain compatible with installed runtimes, and Reactor cleanup failures are reported without turning a completed render into a failed job.
- Media deletion confirmations remain usable on small screens, and iOS pinch gestures no longer accidentally change the selected preview.
- Reviewer model and effort pins survive settings reloads and follow-up reviews; provider-access refusals and zero reviewer coverage produce actionable status.
- Queued pull-request actions require complete assessments for the current head, manual merges stay pinned, and failed auto-merge revocations remain visible.
- Empty dependency audits no longer accept an unrelated diff-only verdict; fidelity findings retain actionable evidence and investigated issue outcomes.
- Retired CoS review alerts disappear from pending actions, completed merged branches are retired before recovery tasks, and duplicate build-drift alerts are removed.
- Provider gateway presets preserve service-owned credentials, task-composer quick actions remain available, quota reset times show hours, and runtime rows and action labels stay readable at intermediate widths.
- Local pre-push checks include uncommitted work and hidden-content scanning; test isolation, import boundaries, and asynchronous UI assertions are more reliable.
- Release review fixes preserve pending actions after clearing history, prevent process-audit pagination from skipping jobs, and keep private task objectives out of automatic tracker follow-ups.
- Backup status recovers after successful retries, nested Models links retain their selected sidebar section, and Notes handles browser history, failed deep links, and filtered lists consistently.
- Imported image metadata respects catalog sync limits and ignores unsupported parameter fields without corrupting supported values.
- Self-update lock recovery runs before submodule reconciliation, including after an interrupted update.
- CoS agents inherit the selected provider's configured effort when task fields are blank, pass it to CLI and TUI launches, and record the resolved setting.
- Issue claims preserve manual blockers and require explicit satisfied dependencies before clearing a stale blocked label.
- Task capture keeps Add and queue actions available with Quick Templates disabled, preserves app choices after draft restoration, and ignores IME confirmation keys.
- Failed video deletion keeps the gallery item visible, and failed Xcode actions show a visible error without a success message.
- Reviewer health warnings can be dismissed without clearing their underlying configuration fault; trimmed tool schemas retain every granted tool in the discovery index.
- Catalog relationship quotes match the exact outgoing relationship instead of borrowing evidence from another kind or direction.
- Development and deployment guidance matches the private-network security model, current dependency overrides, and migration ownership rules.
