# Release v2.106.0 - Camera Chameleon

Released: 2026-10-27

## Highlights

- Curate casting images by age and look, rate references, and refine them while preserving the original and its history.
- Give universes their own photography direction and optional film finish, including three new original natural film looks.
- Explore redesigns in a conversation and apply editable proposals to a separate copy without changing the original catalog item.
- See release publication and synchronization as separate milestones, with verified recovery when an agent's work is interrupted.
- Research selected model comparison gaps using your choice of provider, model, effort and speed.

## Added

- Casting references can be marked good, bad or rejected; refinements retain their source and age/look context and remain available after navigation or restart.
- Universe photography profiles let you set lighting, optics, materials and optional color and texture finishing for image generation and music-video projects.
- Three original natural photographic film recipes are available for stills and video finishing; existing looks retain their rendering behavior.
- Catalog editors offer multi-turn redesign conversations, editable proposals and same-universe copies with independent identities.
- The local model catalog includes Ministral 3 3B, Gemma 4 E2B and Qwen3 32B, and the Codex provider supports GPT-6.1 Terra Ultra.
- Model comparison research can target selected models and use configurable execution settings.

## Changed

- New installations enable image-generation providers by default.
- Creative actions use visible buttons, and reference images open in a preview with rating controls.
- Release publication and synchronization are shown and independently verified as separate milestones.
- Agent recovery carries verified delivery evidence across dependent investigations, resumed work and checkout moves.

## Fixed

- FableLoom previews the complete compiled image request, preserves explicitly selected references and adapters for exact replay, and refuses inputs a local runtime cannot use. The image composer stays scoped to the selected loom.
- Redesign proposals ask how to resolve a conflict before replacing a newer edit in the editor.
- Catalog reference videos display in full, and saved casting context is reflected in image-refinement previews.
- Catalog views refresh when refinement metadata is attached to an existing image, and series that replace their universe's style no longer inherit its photography negatives.
- Canceling film finishing retains the original image and keeps the cancellation through a restart.
- App task forms preserve Git-related preferences when a repository probe is refused or interrupted.
- Model-comparison research requires a selected model, and release status does not claim publication without verified evidence.
- Interrupted agent delivery and checkout retirement preserve ownership, uncertain branch references, source work and verified receipts through recovery.
- Windows agent processes retain settlement evidence through cancellation and handle command arguments safely.
- Release validation collects bounded independent failures and improves Windows and browser test isolation without relaxing their checks.
