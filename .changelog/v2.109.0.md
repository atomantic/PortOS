# Release v2.109.0 - Clapperboard Kestrel

Released: 2026-11-01

## Highlights

- Storyboard panels now drive music-video renders: a shot's still is rendered from its panel's direction before it is animated, Render becomes the clip's primary action, a panel can pick a set camera so the shot sends that wall's photo plate, and a panel can choose which catalog image Make sends for each linked cast member, place or object.
- A recurring music-video section can be planned, previewed and rendered as one timed generation instead of shot by shot.
- Lyric alignment on Apple Silicon is far more reliable: PortOS treats a Rosetta session as Apple Silicon for MLX, rebuilds wrong-architecture or Intel-wheel lyric venvs, keeps a compatible venv's own interpreter, and stops venvs inheriting the host Python.
- The sidebar keeps up on its own: Series, Universes and Music Video lists update when a record changes, and every music video project gets its own row under Music Video.
- The command palette and voice navigation understand multi-word phrases such as "brain ideas", "chief of staff agents" and "digital twin goals".
- Runtime and harness updates (Node.js, PM2 and coding-agent CLIs) appear as actions in the Review Hub and notification bell, and finished GitHub notifications are marked done automatically.

## Added

- Render a storyboard shot's real still first, then animate that still into the clip; Clip from storyboard uses the panel's direction as guidance.
- Storyboard panels can pick a set camera, sending that wall's photo plate with the shot.
- A storyboard panel can name one catalog image per linked cast member, place or object for Make to send; the Cast & sets tab lists each record's images.
- Plan, preview and render a recurring music-video section as one timed generation.
- Music video projects listed as sub-navigation under Create › Music Video, with the open project highlighted on every stage.
- A Fast/Standard speed selector for Grok Build.
- Runtime and harness updates surface as required actions in the Review Hub, Actions and the notification bell, with security releases at high priority.

## Changed

- The shot editor is regrouped around one picture and named setting groups, and the storyboard panel editor fits on one desktop screen.
- Shot and storyboard locking are removed from clip workflows.
- The Suno song checkpoint stops before download, so only the approved render spends a download, and it can approve a version the director revised in Suno.
- Grok clips are requested at 720p and record the size actually delivered.
- CLI and API code reviewers get a 600-second review budget when the provider timeout is still the untuned default.
- Finished GitHub notifications (closed or merged threads, folded CI repeats, PR-workflow-owned threads) are marked done automatically instead of alerting.

## Fixed

- Lyric alignment venvs on Apple Silicon: Rosetta sessions count as Apple Silicon for MLX gates, wrong-architecture and Intel-wheel venvs are rebuilt with the same Python command, universal venvs survive an older replacement Python, framework Python load paths are kept, and venv tests no longer inherit the host Python.
- Lyric section markers that drifted one sung line late are re-anchored on existing projects, and lyric headers stay on the first cue of a merged gap.
- A Suno render finishes before the M4A is exported.
- A shot keeps its named cast sheets when it has no song section, and a cold-open shot with Clip sound gets a clip that has sound.
- The command palette finds pages from multi-word queries, and voice sends section + page phrases to the right page.
- The sidebar updates its Series, Universes and Music Video lists when a record changes and announces newly created series and universes.
- UTC cron schedules fire at UTC on hosts not running in UTC, the Codex five-reference cap is respected, and Digital Twin no longer makes a silent AI call.
- The onboard tools registry is protected from Data Manager purge, and music library records are no longer described as local-only.
- Grok code reviews return a parsable verdict, and grok's no-tool posture removes every built-in tool.
- Pages for Creative Director pickers, Brain Config, Goals, style presets and detail views show retryable errors instead of defaults or "not found" when reads fail; the FableLoom editorial run follows socket pushes instead of a 5-second poll.
- GitHub inbox Refresh stays busy until the newest account sync finishes, and the media lightbox note no longer shows Saving… with nothing pending.
- iPhone Safari no longer zooms the page when you tap a text field, and the Chief of Staff workflow timeline legend wraps on phones.
- A failed FableLoom episode import is reported in the Episode Composer and stays visible through Retry.
- CoS runs whose work already reached the default branch settle, forge-merged branches checked out outside managed roots are retired, and a blocked audit task completes when replay verifies its findings.
- Git diagnostics stay in English under a non-English locale, and the shot render selector no longer overflows its column.
