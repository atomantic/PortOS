# Release v2.81.0 - Mood Board Lantern

Released: 2026-09-29

## Highlights

- **Mood boards come alive:** boards analyze images for emotion and feel (not just literal content), keep running on the server while you navigate away, compose a collage and board style with a poster, re-host external pins, and import private Pinterest boards through your signed-in browser. Images open in the standard lightbox and deep-link by URL.
- **Music video production:** start, monitor, stop and resume a server-owned production run from the editor, with a code-rendered style, full-length renders with the master song, word-level lyric alignment, and loudness/drum-onset feature tracks.
- **Motion blur for compositions:** choose Off, Light or Film blur when rendering HTML compositions, with frame-exact MP4 export for code animations.
- **Accessibility pass:** focus-trapped, Escape-dismissable fullscreen terminal and Daily Briefing, popovers that move focus and close on Escape, a screen-reader-friendly Rapid Reader, corrected heading order and landmarks, and visible Ambient controls on keyboard focus.
- **Sturdier APIs:** many routes now validate bodies and queries and answer bad input with 4xx instead of 500 (git writes, prompt stages, Jira ids, usage, history, browser logs, memory decay).
- **Safer backups and catalogs:** pg_dump verification streams instead of exhausting server heap; concurrent catalog edits from sync and Settings no longer erase each other.
- **Models and providers:** Claude Sonnet 5.5 benchmarks, refreshed Claude model defaults, IBM Granite 4.2 in the local LLM catalog, and working catalog/model Refresh buttons.

## Added

- Mood board analysis captures emotion and feel; gallery prompts are reused as captions; board collage compilation, video frame extraction and composed board styles.
- Import private Pinterest boards through the signed-in browser.
- Music Video production run panel, automation-first create flow, universe and cast setup, code-rendered style and beat/phrase-aware tools.
- Shutter motion blur for HTML compositions; frame-exact code animation MP4 export.
- Launch video overview card can be dismissed; the app issues tab hides in-progress, needs-input, needs-decision and blocked labels by default.
- agy relaunches on its conversation when it exits to the launch shell.

## Fixed

- Body-less POST/PUT requests reach handler validation instead of failing obscurely; loop and message-action caller errors return 4xx.
- CoS agent output summaries keep line breaks; the password-risk warning no longer appears when the server is unreachable.
- Eye exam edits and deletes address records by stable id; series premise honors the 20,000-character cap.
- Quality snapshots are recorded per UTC date with deterministic tie-breaking.
- Killed test runs' temp directories are reclaimed promptly; the MaxListenersExceededWarning on socket connect is gone.

## Internal

- Many API surfaces moved from positional flags to named options; CI jobs have explicit timeouts; slash-do installs are pinned to one version; dependency bumps (engine.io, ip-address, postcss).
