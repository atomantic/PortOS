# Release v2.100.0 - Honest Lantern

Released: 2026-10-21

## Highlights

- **Failed reads show an error with Retry, not an empty list:** Brain, MeatSpace, Messages, Privacy, Tribe, Digital Twin, creative panels, settings, sharing, Chief of Staff, provider and model-fallback panels, and the app Edit/Tasks/Automation/Git tabs now say a load failed and offer Retry instead of claiming you have nothing. Privacy organizations never erase their holdings after a failed read, and list enrichments no longer open blank when the saved list fails to load.
- **Chief of Staff data moves into PostgreSQL:** Agent records, task queues and archived completed tasks are stored in the database instead of `state.json` and Markdown files, with only modified agents serialized on save and a bounded working-set cache.
- **Casting reference library:** Each cast member gets a library of variants, tags and render guides, and Music Video frames can be conditioned on those guides.
- **Code Animation Gallery tab:** Code animations get their own Gallery tab with poster thumbnails, and generation can run without a time limit.
- **Sturdier agent runs and cleanup:** A pasted TUI prompt left sitting in the composer is submitted, terminal replies from an attached viewer no longer cancel it, and claim-owner cleanup shows which live runs block it. Checkout retirement, archiving and reaping no longer contend on the claim-ownership lock.
- **Safer backups, restores and sync:** Restoring an older backup converts pre-split Brain and media-collection stores and adopts a pre-May-2026 migration ledger, a restore keeps this machine's federation identity, paused peers stay in tombstone GC so resume cannot restore deletes, and failed peer pushes retry while the peer stays online.
- **Faster, friendlier phone UI:** The dashboard and Brain capture form appear faster on a phone, buttons show a busy state the moment a tap reaches the server, and touch targets are larger across Processes, AI Agents, History, Instances and sharing.
- **Automation and issue tabs:** The app Automation tab opens on the tasks switched on for the app with All/search filters, Run Now no longer needs the per-app schedule switch, and the Issues tab collapses run settings into a summary row.

## Added

- Per-cast-member reference library and Casting-guide conditioning for Music Video frames.
- Code Animation Gallery tab with poster thumbnails.
- Automation tab filters (switched-on tasks, All, search).
- Claim-owner cleanup shows which live runs block it.

## Changed

- Chief of Staff agent records, task queues and completed-task archive live in PostgreSQL.
- Pregate settles its running stage before exiting on a signal and keeps a completed run's receipt.

## Fixed

- Failed list reads across the app now render an error with Retry instead of an empty state.
- Voice output claims are ignored while voice is disabled; Telegram reconnects no longer orphan timers; concurrent local-runtime wakes share one start.
- Goal time blocks use the user's timezone; 7- and 30-day substance averages cover exactly N calendar days; Life Calendar keeps deleted defaults gone.
- Upload and import hardening: bounded ZIP expansion and ChatGPT asset extraction, verified shared bucket assets, operator authority required for social actions and folder imports.
