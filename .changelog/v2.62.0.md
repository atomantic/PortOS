# Release v2.62.0

Released: 2026-09-10

## Highlights

**Chief of Staff and scheduled work**
- Scheduled work now exposes clearer live state, manual starts, maintenance progress, and safer recovery when agents or worktrees are interrupted.
- Task, review, and branch-reconciliation flows now preserve their ownership and completion state more reliably across retries and restarts.

**Providers and review operations**
- Provider override controls now show configured defaults and wait for complete model and voice catalogs before making selections.
- Review and local-model operations now share simpler capability, stream parsing, and fallback behavior, with safer handling for unavailable backends.

**Creative workspaces**
- App quality is now a dedicated full-width audit workspace, while Universe Builder, Writers Room, and media workflows received focused usability and reliability improvements.
- Eidoverse configuration and projection now support a configurable runtime origin and more resilient migration and online reconciliation.

**Communication and everyday UI**
- Messages, Persistent Mind, and other dense surfaces received responsive layout improvements, clearer controls, and better mobile behavior.
- Clipboard, browser recovery, and form interactions now provide more predictable feedback and preserve user state during failures.

## Added

- Added live agent cards to active Chief of Staff tasks and manual starts for perpetual scheduled task drains.
- Added a full-width app-quality audit dashboard and configured-default indicators to provider override controls.
- Added configurable Eidoverse runtime origin and tracking-branch settings.
- Added shared stream-JSON parsing and consolidated media-job failure finalization paths.

## Changed

- Simplified abuse-guard setup, policy presentation, and related scheduled-task handling.
- Tightened provider, model, voice, and task-form selection so asynchronous catalogs and fallback assignments remain consistent.
- Improved Persistent Mind sizing and composer behavior, Messages mobile wrapping, media-generation scrolling, and browser recovery feedback.
- Consolidated sharing, synchronization, and maintenance state transitions around table-driven contracts with narrower imports and safer cache ownership.

## Fixed

- Prevented release and task cleanup flows from duplicating work after interrupted TUI sessions or already-open pull requests.
- Fixed API reference drift, route-graph documentation mismatches, and several stale or unreachable UI controls.
- Fixed review-store cache invalidation, archived-item upserts, pending-task state preservation, and process/worktree cleanup edge cases.
- Fixed test timing budgets for long-running Eidoverse migration projection and delayed client purge confirmation rendering.

## Removed

- Removed the unused CoS missions subsystem and other unreachable mission fields.
- Removed redundant helper copies and duplicate stream, finalization, and description-folding implementations in favor of shared owners.
