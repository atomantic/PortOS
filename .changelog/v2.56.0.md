# Release v2.56.0

Released: 2026-09-02

## Highlights

- PortOS gains a gated three-stage PR review workflow with posture-driven providers, configurable PR actions, per-PR triggers, verified reviewer-model guidance, and fail-closed safety checks for external review work.
- AI access becomes more flexible with Codex account readiness, ChatGPT subscription sign-in and text workflows, fleet LLM setup guidance, a managed Slotstream runtime, and clearer provider/model compatibility feedback.
- Large model downloads are safer with refuse-before-you-download disk preflight, resumable weight transfers, partial-file accounting, stronger ETag handling, and platform-aware llama.cpp and vLLM setup.
- CoS and operator workflows become more actionable with Persistent Mind proposals based on observed actions, one-click agent relaunch onto a new provider or model, queued install-wide schedules, managed-app update progress, and improved task/review recovery.
- Security and privacy boundaries are reinforced across public review, repository text, ChatGPT ZIP imports, data-root writes, peer sync, hosted sessions, and API-billed federation metrics.
- PortOS is more resilient on Windows, mobile browsers, and long-running sessions through native worktree parsing, responsive layout fixes, bounded async socket handlers, safer timers and child processes, and more reliable production UI rebuilds.
- Generated artifacts and dependency hygiene receive stronger guarantees with content-addressed route manifests, structural position-invariance checks, schema-composer coverage, shared provider mirrors, and the maintained @cantoo/pdf-lib package.

## Added

- Added the three-stage PR reviewer with configurable stage providers, a PR action provider, per-PR scheduled triggers, external-PR coverage, and model-abuse isolation.
- Added Codex subscription sign-in, ChatGPT subscription text workflows, account readiness reporting, verified no-tools reviewer recommendations, and guided fleet LLM provider setup.
- Added Persistent Mind operator-action observation and automation proposals, CoS agent relaunch with provider/model switching, and install-wide scheduled-task queueing.
- Added Slotstream as a PM2-managed local runtime on Models → LLMs.
- Added disk preflight and resumable downloads for model weights, including partial-byte accounting and safer conditional-request handling.
- Added Prompt Guard installation gating on Hugging Face access, broader managed-app document browsing, forge issue label hiding, and evidence-led module hygiene audits.
- Added responsive-grid CI selection, schema-composer and generated-manifest guard coverage, and additional client accessibility enforcement for icon-only links.

## Changed

- Provider safety decisions now use runtime posture and capability contracts instead of hardcoded vendor lists, while switched-off providers stay out of setup warnings and API-billed instances stay out of federated usage totals.
- Video Gen model selection now exposes loading state and caches status payloads, and media submission contracts share one hardened service.
- Managed-app updates report progress over the socket path, rebuild the production UI when needed, preserve the trusted origin, and clean up merged worktrees with their branches.
- CoS review and task state transitions now share socket updates, preserve scheduled routing, and retain queued improvement metadata through recovery.
- Generated API route records are keyed by declaration content rather than line position, and the position-invariance guard is enforced structurally.
- The Scalar API reference dependency is bounded by a bundle budget and the abandoned pdf-lib dependency is replaced with @cantoo/pdf-lib.

## Fixed

- Fixed public-review environment and model-selection gaps that could leak auth into child processes, accept unsafe model choices, or block ordinary agent tasks with an unrelated review gate.
  - Fixed data-root guard gaps in review and detection paths, user-action ledger reads and writes, ChatGPT ZIP member validation, Apple Health cleanup, and peer-pull authorization.
  - Fixed Codex turn cancellation and startup races, stale CoS agents and timers, child-process stdin failures, socket teardown rejections, and direct CLI spawn failures.
  - Fixed local-LLM playground timeout handling, provider model-id normalization, Grok thinking-effort propagation, MTPLX install flow, and Windows command shims and path separators.
  - Fixed managed repository cloning and update recovery, app-update progress, post-update dashboard reopening, and stale HTTP wrappers left behind by the socket flow.
- Fixed responsive grids, modal viewport clipping, machine-output wrapping, icon-only link names, and Scalar bundle-budget assumptions across mobile and split-build environments.
- Fixed peer-sync duplicate conflict keys, expected denial logging, unparseable clock ordering, fine-tune checkpoint recovery, and media-generation backend probing and retry behavior.
- Fixed generated-manifest drift, schema DDL guard coverage, barrel exports, provider mirror validation, and stale documentation and dependency metadata.
