# Release v2.65.0

Released: 2026-09-13

## Highlights

- **Authored series design reaches the whole pipeline:** You can declare a finite or recurring story intent before generating an arc, and planning, editorial, FableLoom and regeneration all honor that brief instead of guessing — with author ownership preserved across refinement, rollback and older-peer merges.
- **The Mind can save and reuse read recipes:** Governed, versioned read recipes are savable, restorable and exposed to Agent Tools, so a tuned retrieval setup survives closing the editor and can be handed to an agent instead of rebuilt by hand.
- **Backup and restore now verify before they write:** Snapshots are checked against their manifest hashes and file checksums, failed or unmanifested snapshots are kept out of restore entirely, older database dumps are made ready for the current app, and restores across machine namespaces work again.
- **A scoped local managed-app visitor broker:** Managed apps can host a constrained visitor session — separate app credentials under both instance auth postures, negotiated host capabilities, and admission/observation/action all bounded to the approved app, individual and world. Host provisioning stays off by default and uncertain or expired authority is revoked.
- **Messaging delivery survives failures:** Beeper no longer double-sends after a lost response, recovers delivery state after database failures, keeps send timestamps correct through reconciliation, and bounds its response reads and retry backoff at the deadline.
- **A broad accessibility pass:** Keyboard operation for Dashboard Arrange, folder filing, clip reordering and goal reparenting; a real `<h1>` on five headings-less routes; roving tabindex on four hand-rolled tablists; Shift+Tab released from the Shell terminal; conditional errors announced; and Banner tone no longer signalled by color alone.
- **Clearer agent and quota reporting:** Run Now shows a live task card for its pre-agent checks, preflight cards no longer strand on the idle-review tier, and the Codex usage card ranks its two quota sources by meters rather than by clock so a corrected reading wins.
- **Safer PR review inputs:** Hidden Unicode and compressed payloads are blocked in a PR diff before any reviewer reads it.
- **Video Downloader can update yt-dlp in place,** with the real underlying error surfaced instead of a bare exit code — the usual cause of a 403 on a download.
- **Local LLM and LoRA ergonomics:** Installed LoRAs come first instead of behind the whole discovery catalog, download progress stays visible off Discover, and the playground leads with the prompt and Run action.

## Added

- Authored series design briefs guide Pipeline planning and editorial prompts; FableLoom honors finite and renewable designs, and explicit clears survive peer sync.
- Scene progression explains stalled scenes through tactics.
- The Mind saves, versions and restores governed read recipes, and exposes saved recipes to Agent Tools.
- A scoped local managed-app visitor broker, with documented optional host credential, bounded cancellation, indexed API route domains and registered validators. A visit ended through the action channel records its cleanup receipt, so the follow-up cleanup call stays idempotent.
- Schedule cards are reused for app automation overrides.
- Task entry form controls are reordered for immediate actionability.
- yt-dlp can be updated from the Video Downloader page.
- Contributor issue claims and PR acceptance are documented.

## Changed

- Perpetual drains render as bounded runtime bars per recurrence instead of one endless band, and the bar is named for screen readers.
- Quota readings are ranked by one shared last-write-wins rule instead of three hand-rolled ones, and the quota slot is stamped on write so a corrected reading still reaches peers.
- App quality category breakdown sorts by ascending score, and dependency-freedom quality scores are explained.
- Client builds publish without clearing the live `dist`.
- Nested Kimi CLI usage is attributed to its own provider.
- AgentCard runtime presentation is extracted for reuse.
- Bounded cleanup quarantine is retained across broker restart.

## Fixed

### Backup, restore and database
- Snapshot manifest hashes and file contents are verified (by checksum) before restore; failed, unreadable or unmanifested snapshots are refused.
- Older database restores are made ready for the current app, and restores work across machine namespaces.
- Database deletion binds to the inactive backend, a dump that fails mid-stream aborts its transaction, and resumable restart loops on cleanup failure are stopped.
- Partial file restores refresh state afterwards, legacy recovery files are retained on directory errors, and catalog restores project into universe canon.
- User-entered backup excludes are anchored, so a bare `cache/` can no longer match at every depth — and so is the selective-restore include, which could otherwise restore a same-named nested directory the user never selected.
- OS metadata a file browser drops into a snapshot (`.DS_Store` and friends) no longer strands an otherwise intact snapshot at the integrity check, and an unmanifested file is named in the error instead of leaving a dead end.

### Messaging
- Beeper: no duplicate sends after a lost response, delivery state recovered after database failures, send timestamps preserved through reconciliation, ambiguous confirmation matching tightened, JSON response reads bounded, and retry backoff cancelled at the deadline.
- Pressing "Check delivery" seconds after sending no longer records a false "unconfirmed" verdict or cancels the automatic confirmation that was about to succeed.

### Story pipeline
- Narrative bible repairs get time to finish, complete arc revisions that fit after compression are preserved, and canon introduced in saved issue plans is retained.
- Incomplete Slotstream checkpoints stay unavailable until a retry finishes; Reactor videos survive a cancellation that arrives during finalization.
- A failed audio mux no longer marks a finished CD stitch as failed.

### Accessibility
- Dashboard Arrange move and resize handles work from the keyboard, a keyboard grab is cancelled when Arrange mode ends, and a stepped widget scrolls into view. A mouse drag begun while a keyboard grab is open no longer commits a card to the wrong slot.
- Folder filing, clip reordering and goal reparenting work from the keyboard.
- Five heading-less routes get a semantic `<h1>` via PageHeader; four hand-rolled tablists get TabPills' roving tabindex.
- Conditional error UI is announced and Banner tone is no longer signalled by color alone; `role=menu` is dropped from popovers that don't implement its keys.
- Shift+Tab is released from the Shell terminal and screen-reader mode is enabled there.
- CoS and Brain mobile tab bars collapse to labelled dropdowns; the five zero-account calendar views get a path to Add Account.

### Agents, tasks and reliability
- An unknown task status or priority no longer deletes the task, and multi-line task descriptions are normalized on update instead of corrupting the task file.
- Manual app tasks are acknowledged immediately with admission timing logged.
- The preflight progress reporter resolves its return before catching, so a synchronous reporter cannot throw out of the security scan.
- Explicit TUI cancellation is preserved without an exit signal; `runYtDlp` keeps one return shape by reporting output on the cancel path.
- Trailing commas are tolerated when rescuing a printed no-tool stage deliverable.
- The managed-visitor bridge token is stored in the private credential store and resolved live.

### Data integrity and UI
- An unreadable collection type `index.json` fails loudly instead of resetting its config slot; an unreadable sync base-hash file no longer silently disables conflict detection.
- `fetchWithTimeout` is bounded through the response body, not just the headers, and the body deadline stays correct across `clone()` and double reads.
- A HuggingFace LoRA whose model family cannot be detected now surfaces its picker instead of failing silently when you have left the Discover tab. Model download metadata lookups are bounded; Agent Tools evaluation stays fixture-only and incompatible recipe metadata is isolated.
- A slow fetch for the previous record no longer lands on the current one; a message detail read for a no-longer-open message is dropped.
- MarkdownOutput keeps intraword underscores literal and clamps heading levels under a `baseLevel` band.
- The macOS Ollama.app upgrade is staged so a failed install rolls back instead of destroying the working one.
- Scheduled task prompt preview layout is bounded.

## Internal

- Test and CI hardening: an async-effect guard registered for test selection, the a11y DndContext guard closed against quoted-string forgery and per-context sensor resolution, a historical SQL fixture replayed across PostgreSQL versions, build-ID and backup fixtures isolated, and Windows path/separator handling fixed in several fixtures.
- `detachedSpawn`'s PID wait is configurable, fixing a Windows CI flake.
- `jsonWriteback`'s exception key updated for the `@babel/parser` 8 tokenizer change.
- Dependency bumps: `@babel/parser`, `zod`, `three`, `lucide-react`, `@cantoo/pdf-lib`, `happy-dom`.
