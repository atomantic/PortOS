# Release v2.82.0 - Sing-Along Storyboard

Released: 2026-09-30

## Highlights

- **Music videos follow the song:** lyrics import automatically and align to vocal phrases using Whisper alignment and Demucs vocal stems; snaps stay inside director-set windows and never overlap adjacent lines. Shots are directed from cast, sets and lyric markers, and frames are conditioned on their scene's set plate at the project's aspect ratio.
- **Steadier lip-sync takes:** a take goes stale only when its own sung window changes, a sustained loudness change is detected, and a plain re-encode of a dense mix no longer invalidates takes. Transcript-guided lip-sync can be switched off per project.
- **Easier music video workflow:** stage tabs, a sticky next-action header and a docked preview; composition documents render with the song and honor per-scene layers; auto-review sampling now covers every shot; phone-sized controls meet 44px tap targets.
- **fal.ai video generation:** a model catalog with per-model request bodies and cost estimates, choice of resolution and provider audio in Video Gen, and priced clips so a dollar cap can bound Creative Director spend.
- **Federated media that holds up:** Media Collections gain a host-or-copy sync mode with local/remote state, and peer-hosted streaming tolerates disabled peers, stale entries and stalled bodies.
- **Usage reporting:** Claude Code tokens per model across federated peers, correct Antigravity/Grok session counts, local models kept out of the Claude card, and fixed date pickers and bar charts on the Usage page.
- **Models and recovery:** GPT-6.1 Sol in Codex presets and model comparisons, and a CLI to reset a lost instance password.

## Added

- Music video: automatic lyric import, Whisper alignment, Demucs vocal stems; development artifacts and a Cast & Sets check-in stage in the autopilot; shots directed from cast, sets and lyric markers; project composition documents rendered with the song; stage tabs with a sticky header and docked preview; a toggle for transcript-guided lip-sync.
- Video Gen: fal.ai model catalog, resolution and provider-audio selection, cost estimates; one-click install of motion skills in the launch video form.
- Federated Media Collections host-or-copy sync mode.
- Usage: per-model Claude Code token report across peers.
- `GPT-6.1 Sol` benchmarks and Codex presets; a lost-password reset CLI; a document on local Jev feasibility for voice navigation.

## Fixed

- Music video frames use the project aspect, pin clip lighting, and stay conditioned on their set plate; mood-board captions no longer leak into motion prompts.
- Lip-sync take staleness is judged on its own window, with loudness changes detected and re-encodes tolerated.
- Cast & Sets images count against production run limits; qwen image MPS decode hardened.
- Detached launches are retired when a zombie holds the process group; shipped Codex models survive a lagging CLI catalog refresh.
- Usage page: half-typed dates, accessible date inputs, bar heights, and damaged scan files no longer risk overwrites or re-billing.
- Isolated Codex claim reviews pass the repo trust check.

## Internal

- Flaky and environment-dependent tests removed or stabilized; DST day-count bug fixed; inline delay helpers consolidated; beeper dispatch uses named options.
