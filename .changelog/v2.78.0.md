# Release v2.78.0 - Swift Firefly

Released: 2026-09-26

## Highlights

- **Less background traffic:** dashboards, creative tools, Brain, and Chief of Staff now receive live changes instead of repeatedly fetching unchanged data.
- **Lighter browsing:** compressed responses, compact media thumbnails, smaller app icons, and batched collection reads reduce the data needed to use PortOS.
- **Paint music in stereo:** Music Designer can paint a spectrogram up to ten minutes long, with responsive previews and an optional visual repaint pass.
- **Make launch videos:** ask Chief of Staff to create a video from an app's details, render local HTML compositions, and prepare posters and sharing downloads.
- **Consistent creative direction:** decks and creative commissions can draw their style from a universe or mood board, and Code Animation can use a music-library soundtrack.
- **Keep your work:** overlapping saves, imports, restarts, and database restores preserve more of your edits, queued work, and synchronization state.
- **Safer host access:** password-free installs reject foreign browser requests and restrict remote actions that can execute commands on the host.

## Added

- Music Designer's painted canvas supports stereo strokes, changing overtones, panning, noise bands, and passage-by-passage composition; existing drawings remain playable.
- Optional “Look and repaint” lets a compatible model inspect each passage's spectrogram before refining it.
- App details can start a Chief of Staff launch-video task with privacy and reading-time validation before rendering.
- Local HTML compositions can become frame-accurate videos with optional music, progress, cancellation, thumbnails, and Media History entries.
- Video tools can select a poster and prepare downloads for sharing.
- Decks and creative commissions can use universe and mood-board style references; commissions resolve those references afresh for each run.
- Code Animation can pick a soundtrack from the music library.
- App quality checks can target categories scoring below the app's overall composite.
- Claim swarms support up to twelve concurrent agents.

## Changed

- Dashboard widgets, Actions, Brain, Digital Twin, MeatSpace, Ambient, and Chief of Staff views refresh from saved changes and lifecycle events.
- Creative Director, FableLoom, Code Animation, media queues, music and image renders, sprites, datasets, and 3D generation receive live progress and completion updates.
- Provider, model, browser, fleet, and process status observations are shared across viewers, reducing duplicate status probes.
- Eidoverse travel panels share destination checks and receive projection and peer-capacity updates.
- Media grids use compact thumbnails, app icons are served at display sizes, and API and built-client responses are compressed.
- Media collection covers and picker memberships load in batches, while Code Animation history loads a page at a time.
- Painted music previews render away from the main interface, keeping the editor responsive during synthesis.
- Deck prompt generation improves batching and progress reporting.
- Chief of Staff no longer shows the recommended maintenance-order card and runner in Schedule.
- Unattended terminal sessions can recover from truncated responses, with bounded retries before provider failover.

## Fixed

- Series bible edits, manuscript format changes, Catalog saves, and Daily Log drafts no longer overwrite newer or switched-away edits.
- Universe imports merge against current canon and season data after lengthy processing, preserving edits made while an import runs.
- Catalog edits and revision history save together; retried commits avoid duplicate ingredients, and parent links survive paginated synchronization.
- Database restores handle older backups with newer relationships, wait for active database work, and reset memory and Catalog synchronization so peers can catch up.
- Failed database dumps preserve restorable backups; unavailable inventories and backup failures remain visible and retryable.
- Missed daily backups can catch up after a restart, and unreadable settings no longer silently disable scheduled work.
- Restored Chief of Staff settings survive recovery, agents drain before runner restarts, and queued media jobs remain queued during shutdown.
- Chief of Staff keeps active agents visible while reads are pending, supports perpetual claim refills alongside targeted claims, and streams feature-agent output correctly.
- Interrupted Music Video renders recover their state at startup; completed paid video renders can be recovered without paying for a second render.
- Render views reconcile after missed completion events and reconnects, and job-status failures offer recovery instead of remaining stuck.
- Apple Health imports update partial totals, serialize overlapping writes, and avoid adding duplicate daily totals from multiple devices or import sources.
- Tribe contact dates follow the user's timezone, and deleted people and their retained audit snapshots expire after the retention period.
- ChatGPT re-imports update the existing conversation memory and preserve earlier assets if a re-import fails.
- Calendar synchronization deduplicates batches and protects overlapping cache updates; Beeper reconciliation resumes bounded sweeps and handles edits and unsends.
- Mail synchronization preserves cached messages until coverage is complete, retains concurrent account changes, and makes deletion failures retryable.
- Older peers preserve newer universe and commission fields they cannot represent; media synchronization validates accepted assets and bounds incoming response sizes.
- Peer pairing and media access continue to work when the saved peer password is removed, while credentials stay at their configured destinations.
- Browser-origin and host checks protect password-free installs from cross-site and DNS-rebinding requests; host-executing HTTP and socket actions require operator authority.
- Multiple PortOS installs on different ports no longer overwrite each other's login cookies, and session refresh detects writes from another process.
- Code-review providers always use the supported read-only review posture, and Settings explains unsupported reviewer configurations.
- Provider and harness refreshes retain complete model catalogs and intended preset narrowing; disabled inherited render backends stay disabled.
- Deleted starter providers and prompt entries stay deleted after subsequent updates, and migrations preserve their applied-state ledger through failures.
- Database settings from the environment reach managed server processes, and startup tolerates a database that is still coming online.
- Dependency-update worktrees keep their installs isolated, production startup leaves the development server off, and conflicting checkout updates no longer loop on every agent spawn.
- Playing-card prompts specify traditional pip layouts, series visual overrides are applied consistently, and deleted creative style sources are skipped safely.
- Security media playback can restart without losing audio, graph details follow the selected node, and failed loop actions no longer show success messages.
- Operational logs omit mailbox content, generated issue text redacts personal and network details, and stale screenshots expire without removing evidence needed by open tasks.
