# Release v2.55.0

Released: 2026-09-01

## Highlights

- Brain is more useful at a glance with On This Day and Today's Agenda dashboard views, indexed daily projections, searchable album tracks, and notes on saved links.
- PortOS makes local AI operations easier to understand with refreshed model catalogs, focused LLM views, Codex account readiness, and clearer runtime bootstrap diagnostics.
- Managed app workflows are safer across forks and Git hosts, with GitLab-aware links, recoverable clone operations, merged-branch cleanup, and on-demand update and restudy.
- Media creation gains hardware-aware render lanes, universe style application, FableLoom rendering preferences, and automated fal scene-video production with clearer privacy and allowance guidance.
- Eidoverse source management now tracks world stack versions while keeping the world experience unobstructed and upgradeable.
- Everyday work is more comfortable on small screens and long-running sessions, with auto-sizing textareas, improved music controls, resilient media queues, and safer browser preferences.
- Synchronization, CI, and operator automation become more dependable through batched tombstone maintenance, indexed sync tails, fail-closed review and cancellation paths, and stronger recovery after interruptions.

## Added

- Added On This Day and Today's Agenda dashboard widgets backed by Brain projections.
- Added an operator-action ledger, notes for saved Brain links, and a searchable album track picker.
- Added Codex ChatGPT account readiness reporting and sign-in from PortOS.
  - Added a refreshed curated local-model catalog and separated model-management views for runtimes and libraries.
  - Added clearer cron schedule editing with validation and an explicit discard confirmation for unsaved changes.
  - Added fork-aware managed-app workflows, GitLab support for Brain links, merged-branch cleanup, and on-demand update-and-restudy.
- Added universe-style conditioning to media generation, FableLoom story rendering preferences, and automated fal scene-video production.
- Added Eidoverse source-stack version management and independent video-render lanes.

## Changed

- Text inputs for task descriptions and media prompts now grow with their contents instead of forcing users to work in a fixed-height field.
- Brain daily views read from indexed projections, while local-date calculations share one DST-safe implementation.
- Provider and model surfaces now hide incompatible choices, keep LLM navigation focused, and expose the best available FableLoom scene media.
- Browser downloads use profile preferences, media prompts update immediately after saves, and long-running video work keeps live frames out of the final render surface.
- CI cancellation and review automation now fail closed around required checks, while clone, submodule, lockfile, and application-port recovery preserve more of the user's work.
- Eidoverse, FableLoom, and music workflows receive clearer setup, privacy, accessibility, and mobile guidance.

## Fixed

- Fixed GitLab asset-link parsing so excessive namespace depth cannot turn an asset URL into an unintended repository path.
  - Fixed interrupted repository clones, MTPLX diagnostics, media-job retry behavior, and browser preference writes so failures remain recoverable and diagnosable.
  - Fixed browser preference setup to preserve malformed or unreadable Chrome settings instead of replacing them with an empty profile.
  - Fixed Codex app-server handshake timeouts and shutdowns so failed launches terminate their child process instead of leaving it orphaned.
  - Fixed legacy Brain link filters, scalar action-type queries, DST-sensitive day windows, and repository URL parsing for route-named GitHub projects and deep links.
  - Fixed MLX video watchdog pressure, tombstone base-hash flushing, artist and album eviction batching, and sync-log indexing across crash fragments and stale operations.
- Fixed media generation to preserve universe styles, render privacy choices before handoff, honor provider lanes, and avoid claiming failed template-usage writes succeeded.
- Fixed FableLoom imports, scene previews, hosted controls, and mobile layouts, along with SongBook navigation, zoom, transpose announcements, and fretbox descriptions.
- Fixed fork comparisons, generated route catalogs, incompatible-provider warnings, and managed-install behavior so updates preserve the correct source and local dependencies.
- Fixed delayed TUI paste markers so provider-agent startup waits for the prompt-ready signal.
