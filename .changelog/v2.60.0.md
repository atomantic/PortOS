# Release v2.60.0

Released: 2026-09-08

## Highlights

**Video production**
- Added a full Video workspace: draft standalone videos, plan and dispatch production through Creative Director, gate on revision-specific reviews, and assemble/validate final cuts.
- Video treatment planning now resolves local creative sources, tracks source-revision changes in saved artifacts, and persists revisioned treatments with browsable history.
- Added a queued generative video upscale (LTX-2.5), with a pre-submit source probe, a method picker with disclosure before submit, and macOS MLX + Windows CUDA backends.

**Persistent Mind**
- Added a route panel, session list, thinking presets, and a temporary-route control for Persistent Mind, plus a free local setup path (Ollama + Qwen2.5 7B) for "Grok-box" style hosts.
- Persistent Mind now auto-pauses on hard provider usage limits and auto-resumes once the limit clears, with a clamped continuous-play numCtx self-adjust.
- Persistent Mind's chosen name now shows as the Eidoverse CoS chat sender, and its identity/workspace controls are protected from accidental edits.

**Tailcat federated peers**
- Added Tailcat-based federated peers (no Tailscale account required), with dial-direction/managed serve, peer card forward status, and probe diagnostics.
- Hardened peer lifecycle and HTTPS tunnel handling, fixed a false add-peer startup timeout, and made a failed retry report failure instead of a false success.

**Writers Room & FableLoom**
- Added an optional five-stage character-evolution lens for series and FableLoom plans, judged by the existing character-arc editorial checks.
- Writers Room can now author psychology, sliders, relationship links, and the canonical character framework, with cast-integrity review held to per-character depth rather than a uniform blank count.

**Providers & AI Provider Ops**
- Unified CLI/TUI provider cards, added a shared provider backend management screen, and gave PROVIDER_HARNESSES a command recipe so a backend and harness can be created, not just imported.
- Added the OpenCode Zen provider's model refresh, private local security assessments and specialist models, and portable capability assignments.
- Quota Burn steps are now modeled as scheduled-task references with per-invocation overrides, replacing the old prompt editor.

**Reliability and infra**
- Fixed a data-loss-adjacent test isolation gap where a developer's real stored Hugging Face token could leak into and corrupt a unit test's expectations.
- Fixed CoS job saves 400ing on a null command for AI-agent job types, and hardened several agent dispatch and worktree-cleanup paths.
- Derived several previously hand-copied client constant tables (image-gen capabilities, provider registries) from their server sources instead, closing a class of drift bugs.
