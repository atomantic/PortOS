# Release v2.116.0 - Steady Otter

Released: 2026-11-10

## Highlights

- **Smoother Music Video previews:** shipped layered compositions play directly in the browser, with exact frames when paused; photo sequences and wipes keep playing smoothly, and Safari no longer flashes black between decoded frames.
- **Faster take decisions:** Use, Reject and Bad update immediately, preserve unsaved shot text after a refused change, and avoid redundant project reloads.
- **Camera character:** add handheld shake and footsteps, match shot colors, and finish each camera with its own film look, framing and camcorder marks.
- **More faithful direction:** cast sheets, sets, choreography, vocal articulation and wide shots preserve the chosen medium, identity and intended action.
- **More rendering control:** choose an image service per still, refine any frame take with references, share a clip across intercut returns, and set hosted-provider parallel limits.

## Added

- Handheld camera takes with shake and footsteps sliders, a live preview, and a new take baked from the steady original; layered compositions offer the same motion per video or shot.
- Shot color matching before the film look, with adjustable strength and outlier warnings, including document-page renders.
- Per-camera finishing looks, 4:3 and 3:2 framing, overscan, inherited cut defaults, and optional camcorder date and recording marks.
- Per-video and per-shot controls for layered motion and texture.
- Frame rendering service and model choices in the shot editor, frame refinement with optional references, end-frame checks, and frame checks through Claude Code or Grok.
- Shared source clips for intercut returns and adjacent short-shot sequences, with one charge shown for each shared clip.
- Provider-side deletion for saved Runway and fal.ai renders, with provider request ids retained on the original render and automatic deletion available after saving.
- Individual-model research in Model Comparison, refreshed local model choices including LFM3 Audio 2B and Nemotron 3 Super 120B, and Claude Fable 5.2 in shipped provider choices and comparison data.
- Parallel rendering limits for hosted image and video providers.

## Changed

- Stock layered-composition playback uses native browser media while playing and isolated exact frames while paused; customized and unverifiable documents retain isolated playback.
- Native composition previews now follow template camera moves, texture, title cards and controls more closely.
- Cast and set planning keeps explicit rendering media, neutral person references, requested atmosphere, procedural supporting-cast behavior and consistent identities.
- Music Video motion direction preserves stillness, continuous or independent movement, synchronized choreography and readable singing mouths; wide shots emphasize recognizable silhouettes.
- World maps show compact set markers with readable labels, a selected footprint and a set list that zooms to the chosen location.
- Local MusicGen dependencies receive security updates, and the in-app macOS FLUX.2 installer uses its verified package lock.

## Fixed

- Marking a selected take bad selects the next good take; concurrent take decisions no longer let an older reply undo the latest choice.
- Changed shot inputs mark selected frames and dependent clips stale, and restoring the original inputs makes them current again.
- Shot sheets, prompt previews and server-side renders agree on camera rules, references, focal subjects and lyric regions; missing picked references fail visibly.
- Still-image effects honor Use end frame, and short-clip notices no longer collapse the shot editor.
- Preview shot counters follow the pictured frame, wiped frames survive skipped frames and seeking, and saving outside the song avoids an unnecessary exact-frame wait.
- Hung shot overlays fail with a useful error instead of remaining stuck.
- Older peers' incoming Previz stories are converted before merging, preserving cross-version editing.
- Media previews refresh after history changes, failed music imports remove temporary uploads, and derived media no longer offer to delete an original provider request.
- Stalled model hosts retry recovery after the cooldown; slow model searches and external requests return bounded, readable errors.
- Model Comparison shows current task costs and calibrates nearby scores without discarding fidelity holds for missing metrics.
- Dependency automation recognizes workflow and Xcode dependencies, skips truly dependency-free repositories, and accepts completed no-op runs.
- GitHub App reviewers are recognized correctly, and re-claimed clean checkouts are cleaned up after earlier merged work.

- Color matching now renders valid corrections, retains samples until measurement completes, and preserves newer take choices when measurements finish.
- Shared clips cover every return, reject unsupported source lengths before rendering, and use matching production estimates; cut sequence clips are no longer offered as longer sources.
- Paused preview frames refresh after look or title edits; instrumental title cards appear, timed-out fonts stay consistent, and new render failures remain visible.
- Shared-take saves report partial failures and prevent duplicate submissions; Undo restores earlier asset marks, deleted media stays deleted, and attention reflects the assets actually played.
- Claude image checks confine file reads to their staged image directory while preserving configured authentication; failed image submissions remove temporary uploads.
- Dependency inspection stays eligible when depth or read limits leave files unexamined, and completed PR checks remain bound to their original forge.

## Internal

- CI reuses verified database and media packages with daily cache refreshes; browser tests move pixels more efficiently.
- Updated quality measurements and regression coverage for rendering, federation compatibility, dependency probing and agent completion.
