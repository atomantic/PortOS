# Release v2.51.0

Released: 2026-08-27

## Highlights

- Persistent CoS mind gains an optional supervisor, conversational runtime, replayable context, configurable AI profiles, and runtime telemetry for safer long-running interactions.
- Managed app controls now cover feature overrides, registration removal, pull requests, AI assignment mappings, and navigation that respects disabled integrations while preserving direct URLs.
- Repository automation now audits branch and worktree state, synchronizes managed apps, holds forge-dependent work during outages, and fails closed before mutating unknown repositories.
- Local model operations gain in-app llama.cpp updates, measured image readiness, provider endpoint probing, normalized rate-limit state, catalog refresh automation, and safe persistence of model settings.
- Scheduled agents can receive configurable data preloads with explicit no-change verification and secured input handling.
- OpenWorld gains operational building telemetry, clearer health status, improved visuals, and lower grass and particle rendering cost.
- Backup snapshots can be downloaded from the UI, while remote desktop reconnects are bounded and authenticated.
- Rapid Reader adds Accelerando content and broader digit-span defaults; image workflows expose Windows execution provenance and local readiness.
- JIRA automation can resolve Cloud assignees and decompose oversized epics, while optional JIRA collectibles follow feature settings.
- Release and PR safeguards now include repository-hygiene coverage, local review gates, safer catalog audits, and centralized client error envelopes.

## Added

- Added the optional persistent CoS mind supervisor with admission capacity, lifecycle coordination, replayable context, conversational interaction, configurable provider profiles, and per-app runtime telemetry.
- Added managed app pull-request management, registration removal, feature controls, persisted AI assignment mappings, and task-description drafts scoped to app context.
- Added repository synchronization automation for managed apps and in-app llama.cpp update support.
- Added a CLI provider-catalog refresh task and configurable scheduled-agent data preloads.
- Added persistent local image execution provenance, measured local readiness, and a Windows execution marker with round-trip verification.
- Added OpenWorld per-app CPU, memory, and uptime telemetry plus an authenticated remote desktop bridge with bounded reconnects.
- Added backup snapshot downloads and new Rapid Reader Accelerando content.

## Changed

- Navigation now derives its sidebar structure from the shared manifest and applies instance feature settings consistently across integrations and OpenWorld collectibles.
- Provider rate limits now persist normalized cooldown windows, and local provider probing, streaming retries, fallback capability gates, and status recovery are more explicit.
- Catalog type settings now live with the catalog, while catalog refresh and audit flows preserve drafts, no-op state, metadata, and lifecycle guidance.
- Scheduled tasks can start immediately when explicitly requested, retain configurable input data, and preserve safe verification boundaries.
- OpenWorld health belts, visual effects, grass, particles, and playback behavior were refined for clearer operation and lower rendering cost.
- API streaming failures now use a centralized error envelope, and dashboard and CoS loading paths preserve progressive state while reducing latency.
- The persistent mind keeps retention, accounting, provider settings, profile drafts, diagnostics, and memory metadata across lifecycle transitions and remounts.
- Release preparation now derives human-readable notes from the complete unreleased commit history and gates manual pull requests on local review.

## Fixed

- Fixed repository-state audits to fail closed on unreadable gates, partial probes, unknown merge checks, and unanswerable repository state.
- Fixed repository synchronization so unknown state, origin-less branches, and forge outages cannot cause a stash or repository mutation to be dropped.
- Fixed managed app navigation, feature override preservation, deleted-detail refetches, overflow-menu layout, route guards, and redirect query handling.
- Fixed persistent mind lifecycle races, admission capacity handling, slow-turn keepalive, profile synchronization, retention isolation, accounting hydration, and retry behavior.
- Fixed empty persistent-mind summaries, forced retries, prompt limits, and memory metadata validation.
- Fixed local LLM migration numbering and preserved saved llama.cpp idle settings during upgrades.
- Fixed stale provider catalog loads, absent capacity configuration, and provider status hooks that could otherwise report misleading state.
- Fixed backup restore scheduling, child-process waiting, subdirectory filters, and other backup test stability issues.
- Fixed catalog audit no-change detection so empty audits cannot create pull requests and dispatched metadata remains covered.
- Fixed JIRA Cloud assignee resolution and epic decomposition in the claim flow.
- Fixed browser bridge fallback and messaging when the agent bridge is empty, while retaining the PortOS CDP fallback for UI audits.
- Fixed task draft restoration and validation, app-context scoping, and exported route regression coverage.

## Removed

- Removed the obsolete command-activity export.
