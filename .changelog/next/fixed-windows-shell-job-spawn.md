- Windows: autonomous shell jobs (e.g. the shipped System Health Check running `pm2 jlist`) no longer fail with `spawn ENOENT` / exit -4058 — the command now resolves through prepareCliSpawn, so a .cmd shim on PATH is launchable under shell:false
- Quieter Windows boot: no bogus MaxListenersExceededWarning from the 11 permanent media-job completion hooks, no 'Failed to start Ollama as a background service' warning on platforms that have no service manager (the foreground fallback is the intended path there), and media-model drift warnings scoped to the current platform instead of repeating the other platform's rows every boot
- Windows: agent process listing was silently dead — it shelled out to wmic.exe, which Microsoft removed from Windows 11, and the failure was swallowed into an empty list so PortOS reported 'no agents running' forever. Replaced with PowerShell Get-CimInstance (in-box on every supported Windows), with the probe failure now logged instead of hidden
