- Hugging Face model search no longer fails with a bare "fetch failed". The Hub's HTTP/2 GOAWAY on a retired pooled connection is retried once (opt-in `retries` on the shared `fetchWithTimeout`), and a repeated failure now names the condition instead of surfacing undici's opaque message.
- Opening Settings → Local LLM no longer bursts the Hugging Face and Ollama registry APIs. Per-repo metadata is cached to disk (`data/cache/`, 7-day TTL) so a known catalog costs zero requests after the first load — even across restarts — and what remains flows through a bounded gate instead of ~36 simultaneous probes. Cold catalog load 1.3s, warm 0.04s.
