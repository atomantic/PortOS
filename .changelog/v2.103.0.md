# Release v2.103.0 - Roaming Storybook

Released: 2026-10-24

## Highlights

- **FableLoom travels:** export portable story packages, choose web-friendly media, and include a standalone player for your own static host.
- **Storyboards connect:** explore an episode as panels, make a shared storyboard from its path, and send chosen art back to scenes or Series Pipeline shots.
- **Clearer delivery:** Chief of Staff separates execution, delivery, and cleanup, shows recovery progress, and keeps routine automated cleanup out of personal Brain obligations.
- **Useful GitHub actions:** inbox threads explain why they need attention and share PR actions with central Actions.
- **More honest costs:** monthly usage charts show estimated dollars by provider, with improved fleet reconciliation and image-generation accounting.
- **Safer recovery:** interrupted work retains ownership and complete preservation evidence while recovery handles more valid checkout archives.

## Added

### Portable FableLoom stories

- Export a portable story package with a versioned runtime contract and bounded media processing.
- Choose web media profiles while preserving short clips, silent audio, and selected stream timing.
- Optionally include canonical character inputs and approved voice references; exports omit credentials and machine-local settings.
- Include a standalone static player with local choices and typed keywords, plus an optional host-provided turn resolver.
- Open an episode's Board view to follow one story path, choose forks, and share that path by URL.

### Connected creative tools

- Make a shared storyboard from a FableLoom episode path and apply selected panel art to its source scene.
- Open Series Pipeline scenes in the shared storyboard editor and apply chosen panel art as a shot's start frame.
- Review storyboard changes per shot and explicitly update one shot or all changed shots without overwriting stage edits automatically.
- Import individual Pinterest Pins into mood boards and use more consistent mobile tools.
- Start Reality with reusable photographic direction and restore the latest starter while preserving customized canon and media.

### Delivery and account visibility

- Show in-flight app quality checks, delivery holds, cleanup ownership, and live recovery progress on status cards.
- Rebase and push ahead app default branches while preserving local work when synchronization fails.
- Credit completed local code reviews on PRs using verified execution receipts.
- Show monthly subscription dollars alongside token usage and provider-stacked estimated API costs.
- Manage imported Timeline data per source with typed confirmation and clear failure recovery.

## Changed

- GitHub inbox rows show action reasons, issue or PR state, and merge readiness; shared PR actions are available from central Actions.
- Routine local validation runs focused tests and structural checks, leaving broad coverage to hosted CI; release candidates still receive full validation.
- Optional local attestation no longer delays the start of hosted checks.
- Video stitching runs as a cancellable job, combines duplicate live requests, and publishes history only after encoding succeeds.
- Casting references and their visuals stay together, and character-look rendering requires explicit visual direction.
- Chief of Staff preserves a completed pre-PR local review through later hosted feedback while continuing to require current hosted checks and approvals.

## Fixed

- Voice exports enforce the shared package-size budget while reading approved references, keeping oversized casts from accumulating unbounded audio in memory.
- An open Series Pipeline view refreshes its changed-shot controls when a linked storyboard is edited elsewhere.
- Hosted FableLoom scene changes wait for the designated output to finish speaking, and stale or failed playback cannot advance a later turn.
- Live story decisions respect their decision windows and audio occupancy, and outline validation measures introductions along the shortest dramatic path.
- Integer motion blur preserves composition frame cadence, and interrupted renders drain their owned work before cleanup.
- GitHub notifications finish automatically after a confirmed PR merge; disabled accounts disappear from the active inbox without losing saved history.
- Editing GitHub accounts preserves trust settings, and PR review intake honors the pinned forge account.
- Monthly fleet totals reconcile overlapping records correctly and keep the current month visibly partial through month end.
- Grok costs include corrected cache, long-context, image, and video accounting; Codex and Antigravity image activity gains durable receipts and reconciliation.
- Usage repair skips unrelated session files, preserves recovery journals, and avoids duplicate recovered image activity.
- Signal checks and chat access honor the saved sync opt-in, with clearer feedback when disabled.
- Concurrent Chief of Staff queue changes and completion handoffs survive persistence and restart recovery.
- Checkout recovery preserves ignored content, staged bytes, private Git state, permissions, and ownership before retirement, with bounded verification of larger valid archives.
- Missing or ambiguous checkout evidence remains an explicit hold; verified historical archives can resolve preservation without inventing successful execution.
- Recovery retains active owners, handles native Git path differences, and avoids reopening completed work or spending a fresh retry budget on routine cleanup.
- Dependency updates include security and compatibility fixes for HTTP, browser-test, and file-locking support.
