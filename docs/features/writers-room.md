# Writers Room

Open **Create → Writers Room**. Organize works in the library, open a work to edit its Markdown draft, and use the writing guide for craft references and length targets. Save draft versions to compare revisions. Backups need the PostgreSQL records and draft Markdown under `data/writers-room/`.

## Write and analyze

- Start a timed free-write with **Write for 10**. Finish or discard the exercise. A finished sprint attached to the open work can append its text to the active draft.
- Run evaluation, formatting, or script and entity extraction from the analysis controls. Results belong to the draft version the pass read. Re-run an analysis when the draft changes and the result is marked stale.
- Review characters, places and objects in the **Story Bible**. Extraction can supplement entries and preserves authored character-framework values. Clear or edit those values directly when you want to revise them.
- Use **Synchronized Review** to compare prose, script and media. Selecting prose highlights its mapped scenes and renders. Unmapped older images remain visible as orphaned. The Cast pane identifies missing authored fields. **Sharpen** offers a proposal, and you choose which individual changes to apply.

## Adapt a work

**Adapt** creates storyboard scenes and queues images for all scenes missing one. Check the renderer and expected cost before running it. Review results and replace an individual scene image from the storyboard. Images land in the work's media collection.

Use the Creative Director bridge to preview a treatment and send it to a new Creative Director project. Use Pipeline promotion to create a comic series and its first issue. The work stays linked to each destination.

## Live assistance and peer sync

**Live Director** is off by default per work. Enable it to request draft continuations after a typing pause, then insert the suggestions you want. Adjust its daily call and preview-render budgets on the work. Budgets reset at UTC midnight. Other model analysis and render actions require an explicit action.

Writers Room content can sync between your own PortOS peers. Work records and draft bodies travel together across enabled peer categories. Scene images travel with their media collection.
