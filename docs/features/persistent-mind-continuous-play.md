# Persistent Mind operating controls

Open **Chief of Staff → Persistent Mind** and review **Mind Context**. The default playbook uses the operator's instructions. **Continuous play** can add a maturity-aware operating phase and a custom instruction block. Preview the composed instructions before saving. Saving a playbook does not start inference.

## Context and thinking presets

Set the host's permitted context range before enabling mind-adjustable context on a supported local provider. Review the current value and the machine's memory headroom in Mind Context. The operator's ceiling and runtime limits bound requests. Adjusting configuration is separate from starting a model turn.

Use the thinking profile to select the provider and model the Mind may use. Self-directed selection applies only within the enabled local thinking presets and their operator-configured limits. Review the current profile and recent activity to see the chosen route.

## Task filing

Give the Mind only the task and managed-app grants you intend it to use. Review proposals or task records in CoS and investigate refusals through their recorded reasons. Its task authority and the general thinking route are independent.

## Persistent Mind phone calls

Configure one recipient in **Settings → Voice → FaceTime Audio** and attach the call host on that Mac. Verify the audio route with a test call. Enable **voice.call-user** under **Mind → Tools** only if you want the Mind to call that recipient. The grant starts off. The model supplies a reason and opening line. PortOS supplies the configured recipient.

Open Mind activity to see whether a call was placed or suppressed. A connected voice tab, quiet hours, an active call, the shared call budget or a missing call host can suppress it. The Mind receives a completed call's transcript on hangup. Critical-notification escalation uses its own opt-in setting and shares the call budget. See [Voice Mode](./voice.md) and [Chief of Staff](./chief-of-staff.md).
