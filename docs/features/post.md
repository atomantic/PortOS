# POST (Power On Self Test)

Open **MeatSpace → POST** to practice mental math, memory, wordplay, verbal agility, ideation and cognitive drills. A **Full** session runs the enabled drills. A **Quick** session samples one from each enabled domain. Morse practice is training-only.

## Choose a session

- **Test** records a score and history for the drills configured for that session. Math and language drills use configured time limits. Cognitive drills can be self-paced or stimulus-driven.
- **Train** gives immediate hints and feedback. Completed runs contribute to practice progress and recommendations. If the results screen reports a failed save, retry there.
- **Benchmark** uses fixed protocols with rotating forms. Compare those runs in the benchmark trend, which keeps results scoped to the active protocol and scorer. Record sleep, caffeine and stress at launch when you want comparable conditions. Treat scores as a practice measure.

Adaptive math difficulty is opt-in. Preview its changes before enabling it. While the multiplication ladder is enabled, its current rung determines multiplication difficulty. Wordplay cache fill is an explicit action and shows the selected provider and model. Daily reminders are optional.

## Memory Builder

Add a song, poem, speech or sequence, then practice progressively revealed chunks, fill-in-the-blank, continuation, speed runs or spaced review. The spaced mode brings weaker chunks back sooner. The built-in Elements song has a periodic-table practice view.
